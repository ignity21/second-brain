* DataFrame
** Exploring a DataFrame
- ~df.shape~
- ~df.info()~: show Non-Null Count
- ~df.describe()~: summary statistics
- ~df.columns~, ~df.index~
- ~df.values~: internal numpy array

** Creating a DataFrame
- From a list of dictionaries(row by row): ~pd.DataFrame(list_of_dicts)~
- From a dictionary of lists(by column): ~pd.DataFrame(dict_of_lists)~

* Selecting
** By Columns
#+begin_src python
df["col_a"]  # Series
df[["col_a"]]  # DataFrame
df[["col_a", "col_b"]]
#+end_src

** By Rows
#+begin_src python
df.loc["row_a"]
df.iloc[0]

df.loc["row_a", "col_a"]
df.iloc[0, 0]
#+end_src

** By Rows and Columns
#+begin_src python
df.loc["row_a", ["col_a", "col_b"]]
df.iloc[0, [0, 1]]
df.loc[["row_a", "row_b"], ["col_a", "col_b"]]
df.iloc[[0, 1], [0, 1]]
#+end_src

** SQL-like Query
- ~query('SELECTION STATEMENT')~: input string similar to statement after WHERE in SQL
#+begin_src python
stocks.query('financial == "gross_profit" and value > 100')
#+end_src

* Slicing
- By Rows: ~df.loc["row_a":"row_d"]~
  - MultiIndex: ~df.loc[("outer1", "inner2"):("outer2", "inner5")]~
- Time Series: ~df.loc["2020-01-01":"2020-03-31"]~
- By Columns: ~df.loc[:, "col_a":"col_d"]~

* Filtering
** by Columns
#+begin_src python
df[df["col_a"] > 0]
df[(df["col_a"] > 0) & (df["col_b"] > 0) $ (df["col_c"] < 0)]

is_black_or_blue = df["color"].isin(["black", "blue"])
df[is_black_or_blue]
#+end_src

* Indexing
#+begin_src python
df_ind = df.set_index('col_a')
df_dropped = df_ind.reset_index() # there is a drop option
df_ind = df.set_index(['col_a', 'col_b'])
df.loc[[('val_a1', 'val_b1'), ('val_a3', 'val_b4')]]
#+end_src

* Sorting
#+begin_src python
df.sort_values("col_a", ascdending=False)
df.sort_values(["col_a", "col_b"], ascending=[True, False])

df.sort_index() # default outer level then inner level
df.sort_index(level="idx_b")
df.sort_index(level=["idx_a", "idx_b"], ascending=[True, False])
#+end_src

* Counting
#+begin_src python
df["col_a"].value_counts()
df["col_a"].value_counts(normalize=True, sort=True) # % of total
#+end_src

** Layering Plots
#+begin_src python
dogs[dogs['sex']=='F']['height'].hist(alpha=0.5)
dogs[dogs['sex']=='M']['height'].hist(alpha=0.5)
plt.legend(['F','M'])
plt.show()
#+end_src
