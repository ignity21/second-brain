#+title: K-Nearest Neighbors
#+filetags: ML

* Overview
- Predict the label of a data point by
  - Looking at the *k* closest data points
  - Taking a majority vote: based on what label the majority of nearest neighbors are.

* Two Important Parameters
- the number of neighbors: *k*
- how you measure distance between data points:
  - By default, Euclidean distance is used, which works well in many settings.

* Measuring Model Performance
- Accuracy = correct predictions / total observations
- Problem:
  - Could compute accuracy on the training set
  - NOT indicative of how well it can generalize to unseen data
- Solution: split data into training set and test set, then calculate accuracy using test set.
#+begin_src python
train_accuracies = []
test_accuracies = []
neighbors = np.arange(1, 10)
for k in neighbors:
    knn = KNeighborsClassifier(n_neighbors=k)
    knn.fit(X_train, y_train)
    train_accuracies[k] = knn.score(X_train, y_train)
    test_accuracies[k] = knn.score(X_test, y_test)
plt.plot(neighbors, train_accuracies, label='train accuracy')
plt.plot(neighbors, test_accuracies, label='test accuracy', linestyle='--')
plt.legend()
plt.xlabel('n_neighbors')
plt.ylabel('Accuracy')
plt.show()
#+end_src

* How to Choose k?
In practice, using a small number of neighbors like *three or five* often works well.
- k=1 -> overfitting
- large k -> underfitting
[[../assets/ML/KNN_2.png]]

* Advantages
- Easy to understand, often gives reasonable performance.
  - A good baseline method to try before considering more advanced techniques.
- Building the model is very fast

* Drawbacks
- Prediction can be *slow* when training set is large.
- Inability to handle many features.
- Particularly bad with datasets where most features are 0.(so-called sparse datasets)

* Code
#+begin_src python
import mglearn
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

k = 3
# 2 features, 1 target (numpy array)
X, y = mglearn.datasets.make_forge()

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3, # 30% test data, common choice 20%-30%
    random_state=21, # seed for random number generator
    stratify=y, # the target label proportions reflect that of the original dataset. e.g. 30% class 0 for both train and test
)
clf = KNeighborsClassifier(n_neighbors=k)
clf.fit(X_train, y_train)

y_pred = clf.predict(X_test)

print("Training set accuracy: {:.2f}".format(clf.score(X_train, y_train)))
print("Test set accuracy: {:.2f}".format(clf.score(X_test, y_test)))
#+end_src
