* Databases
** Relational
- SQLAlchemy Approach
#+begin_src python
import pandas as pd
from sqlalchemy import create_engine
engine = create_engine('sqlite:///mymusic.db', echo=True)

# show all tables
print(engine.table_names())

with engine.connect() as con:
    rs = con.execute('SELECT * FROM Artist')
    df = pd.DataFrame(rs.fetchall()) # fetchmany(size=4)
    df.columns = rs.keys()
#+end_src
- Pandas Approach: ~df = pd.read_sql_query('SELECT ...', engine)~
