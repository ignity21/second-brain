#+filetags: Network

* 网络性能指标
** 带宽
表示链路的最大传输速率，单位是 b/s 。 例：100Mbps

** 吞吐量
表示没有丢包时的最大数据传输速率，单位通常为 b/s 或 B/s。

** 使用率
吞吐量 / 带宽也就是该网络链路的使用率。

** 延时
表示从网络请求发出后，一直到收到远端响应，所需要的时间延迟。它可以表示不同的含义，如：
- 建立连接需要的时间（比如 TCP 握手延时）
- 一个数据包往返所需时间（比如 *RTT* round trip time ）

** PPS
Packet Per Second 表示以网络包为单位的传输速率。通常用在需要 *大量转发* 的场景中。

* Web 服务指标
更能反应实际应用程序的性能。
- 并发连接数
- 每秒请求数 (QPS, Query Per Second)

* 测试对象
- 基于 HTTP 的 Web 应用程序，属于应用层，需要测试 HTTP/HTTPS 的性能。
- 支持多人同时在线的游戏服务器，需要测试 TCP/UDP 的性能。
- 路由器 / 交换机，更关注转发性能，即 PPS 指标
