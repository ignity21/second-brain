* 建立通信流程 [[id:84b36379-a24c-4f36-af77-0aeca362066d][ARP]]
1. 发送方发送已知信息：
   - 发送方 IP 地址
   - 发送方 MAC 地址
   - 目标 IP 地址
   - 目标 MAC 地址填广播地址 ~FF:FF:FF:FF:FF:FF~

2. 交换机关联(缓存)发送方 MAC 地址和物理端口
3. 交换机向网络广播
4. 接收方验证目标 IP 地址是否匹配，不匹配直接丢弃。匹配发送响应包。
5. 交换机根据响应包关联响应方 MAC 地址和物理端口
6. 交换机将响应包发回发送方

* VLAN (虚拟局域网)
通俗理解：在同一套交换机和网线基础设施上，虚拟出多台彼此隔离的交换机。
- 网络隔离、划分安全边界
- VLAN 之间通信必须通过路由
- 独立广播域
  
** 无 VLAN 问题
- 广播风暴，整个网络都会收到奇怪协议 mDNS、NetBIOS、Windows 广播、某些发现协议等等
- 不同部门之间可以直接访问, 容易实现 ARP 欺骗、中间人攻击、广播嗅探

* 3 层交换机
3 层交换机包含 2 层交换机所有功能，加上部分路由器功能，如 NAT, QoS 等等，但是没有 WAN 口
| 功能        | 2层交换机 | 3层交换机 | 路由器 |
|------------+----------+----------+-------|
| 处理协议    | MAC      | MAC / IP | IP    |
| VLAN间通信  | ❌        | ✔️        | ✔️     |
| 有无 WAN 口 | ❌        | ❌        | ✔️     |
