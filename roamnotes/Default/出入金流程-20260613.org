#+title: 出入金流程

| 场景            | 推荐主路线                                    |
|----------------+---------------------------------------------|
| 传统券商入金     | 大陆银行(转HKD) → 香港银行 → Wise → IBKR(转USD) |
| 传统券商出金     | IBKR(转HKD) → Wise → 香港银行 → 大陆银行        |
| 数字货币入金     | 香港银行 → iFast → Kraken → 交易所             |
| 数字货币出金     | 交易所 → Kraken → iFast → 香港银行             |
| 普通换汇/跨境转账 | 香港银行 ↔ Wise ↔ 海外账户                     |
