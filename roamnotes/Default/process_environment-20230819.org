#+title: Process Environment
#+filetags: Linux

* Start-up Routine
- Take values from command-line arguments and the environment
- Often coded in assembly language
- Call to ~main~ could look like ~exit(main(argc, argv))~

* Process Termination
1. Return from /main/
2. Calling /exit/
3. Calling /_exit/ or /_Exit/
4. Return of the last thread from its start routine
5. Calling ~pthread_exit~ from the last thread

** Abnormal Termination
1. Calling /abort/
2. Receipt of a signal
3. Response of the last thread to a cancellation request

* Exit Function
#+begin_src cpp
  #include <stdlib.h> // ISO C
  void exit(int status);
  void _Exit(int status);

  #include <unistd.h> // POSIX.1
  void _exit(int status);
#+end_src
- ~exit~ performed a clean shutdown of the standard IO library.
  - ~fclose~ function is called for all open streams.
