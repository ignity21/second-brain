* 变量类型

** str 有用但不常用的方法
- ~s.partition(":")~ can split "key" -> ["key", "", ""]
- ~s.translate()~
#+begin_src python :return
s = "英文,标点."
trans_table = s.maketrans(",.", "，。")
return s.translate(trans_table)
#+end_src
