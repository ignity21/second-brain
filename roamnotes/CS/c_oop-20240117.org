* Struct or Class
[[https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#c2-use-class-if-the-class-has-an-invariant-use-struct-if-the-data-members-can-vary-independently][Core Guidelines]]
- use structures when member variables are *independent* of each other
- use classes when member variables are related by an "invariant"

* Scope Resolution
#+begin_src c++
Date::Date(int year, int month, int day) {
    Date::year = year; // instead of coding "this->year = year;""
    Date::month = month;
    Date::day = day;
}
#+end_src

* Initialization List
- Prefer initialization to assignment :: In fact, initialization lists ensure that member variables are initialized *before the object is created*.
- Read-only Variables :: class member variables can be declared *const*, *but only if the member variable is initialized through an initialization list*.

* Hints
- Don't forget the *override* keyword to override a virtual function.
- ~int& operator(int row, int col)~: use ~int&~ to modified location of matrix data.
