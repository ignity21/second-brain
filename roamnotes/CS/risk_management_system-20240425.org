#+title: Risk Management System
#+filetags: :Quant:Trading:

A *risk management system* (RMS) forms a very *critical* component of any trading system.

There are 2 places where risk management is handled:
- Within the application – We need to ensure those wrong parameters are not set by the trader.
  - It should not allow a trader to set grossly incorrect values or any fat-finger errors.
- Before generating an order in the [[id:b5b5401b-b2aa-4366-8a62-cffc07279893][OMS]]
  - Before the order flows out of the system we need to make sure it goes through some risk management system. This is where the most critical risk management check happens.
