#+title: =/proc/=
#+filetags: Linux

- The kernel creates them *"on the fly"* as processes access them.

* Help
~man 5 proc~

* System Information
| Directory          | Information                              |
|--------------------+------------------------------------------|
| =/proc/net=        | Information about networking and sockets |
| =/proc/sys/fs=     | Settings related to file systems         |
| =/proc/sys/kernel= | Various general kernel settings          |
| =/proc/sys/net=    | Networking and sockets settings          |
| =/proc/sys/vm=     | Memory-management settings               |

Files:
- =/proc/=
  - =filesystems=, =kallsyms=, =loadavg=, =locks=, =meminfo=, =partitions=, =stats=, =uptime=, =version=, =vmstat=
- =/proc/net/=
  - =sockstat=, =sockstat6=, =tcp=, =tcp6=, =udp=, =udp6=
- =/proc/sys/fs/=
  - =file-max=, =inotify=, =mqueue=
- =/proc/sys/kernel/=
  - =acct=, =core_pattern=, =hostname=, =msgmax=, =msgmnb=, =msgmni=, =pid_max=, =sem=, =shmall=, =shmmax=, =shmmni=
- =/proc/sys/net/=
  - =core/somaxconn=, =ipv4/ip_local_port_range=
- =/proc/sys/vm/=
  - =overcommit_memory=, =overcommit_ratio=

** Modifying Settings Example
- ~echo 100000 > /proc/sys/kernel/pid_max~

* Useful Files in =/proc/[PID]/=
- links :: [[id:9b389f92-25a2-4d87-ab70-70572a7a23fc][Process Troubleshooting]]
  - =exe=: symbolic to file being executed
  - =cmdline=: command-line arguments
  - =stat=: for program
  - =status=: provides a range of information about the process.
  - =cwd/=: symbolic to current working directory
  - =environ=: /NAME=value/ pairs
  - =fd=: symbolic links to files opened by the process
  - =maps=: memory mappings
  - =mem=: process virtual memory (must ~lseek()~ to valid offset before I/O)
  - =mounts=: mount points for the process
