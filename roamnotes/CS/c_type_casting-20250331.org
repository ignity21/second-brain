#+title: C++ Type Casting

* C-style Casting
not recommended, because it is not type-safe
- ~int i = (int)3.14;~
- ~Base *pBase = (Base *)new Derived();~
- ~B *pB = new B(); A *pA = (A *)pB;~ is not safe but it can be compiled.

* Dynamic Casting
- Runtime type checking
- Only used with pointers and references
- Upcasting won't fail
#+begin_src cpp
Derived obj;
Base *pBase = dynamic_cast<Base *>(&obj);
Base &rBase = dynamic_cast<Base &>(obj);

Base *pBase = static_cast<Base *>(&obj); // upcasting won't fail, use static_cast for performance
Base &rBase = static_cast<Base &>(obj);
#+end_src
- For downcasting, the conversion will:
  - check if there is a virtual function in the base class in *compile time*
  - check if all the members in the derived class are inherited from the base class in *run time*
#+begin_src cpp
Base obj;
Derived *pDerived = dynamic_cast<Derived *>(&obj);
if (pDerived == nullptr) { // return nullptr if failed
    cout << "Failed to cast" << endl;
}

try{
    Derived &rDerived = dynamic_cast<Derived &>(obj);
} catch (bad_cast &e) { // throw exception if failed
    cout << e.what() << endl;
}
#+end_src

** RTTI (Run-Time Type Information)
- RTTI is required for ~dynamic_cast~
- RTTI is enabled by default, disable it by ~-fno-rtti~, use ~static_cast~ instead
  - May use ~dynamic_cast~ in *debug mode* and ~static_cast~ in *release mode*
- RTTI is comipled into the binary, so it can be used in runtime
- ~typeid~ operator returns a reference to a *type_info* object

* Static Casting
- Compile-time type checking
#+begin_src cpp
int i = static_cast<int>(3.14);
Base *pBase = static_cast<Base *>(new Derived());
#+end_src

* Reinterpret Casting
- Low-level reinterpretation of bits
- Used for casting between unrelated types. e.g. *casting between a pointer and an integer*
#+begin_src cpp
Foo *pFoo = new Foo();
int64_t address = reinterpret_cast<int64_t>(pFoo);
Foo *pFoo2 = reinterpret_cast<Foo *>(address);
#+end_src
- may useful for casting data in buffer to a struct

* Const Casting
- Commonly used to remove constness
- type must be a pointer or reference
#+begin_src cpp
const int i = 10;
int *p = const_cast<int *>(&i);
int &j = const_cast<int &>(i);
*p = 20;
j = 30;
cout << i << endl; // 30
#+end_src
