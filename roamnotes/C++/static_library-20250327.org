#+title: Static Library

* Creating an Archive
- Using ~ar~
#+begin_src bash
ar rcs libfoo.a foo.o # archive foo.o into libfoo.a
ar -t libfoo.a # list the contents of libfoo.a
#+end_src

* Linking
#+begin_src bash
g++ main.cpp -L. -lfoo -o demo
#+end_src
