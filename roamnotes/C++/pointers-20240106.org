#+title: Pointers

* Overview
| Variable | Type | Memory | Value |
|----------+------+--------+-------|
| pvalue   | int* |   1001 |  1002 |
| value    | int  |   1002 |  1212 |

- &value: 1002
- value: 1212
- &pvalue: 1001
- pvalue: 1002
- *pvalue: 1212

* const
- ~int i = 0;~
- ~const int * p = i~: pointer to constant integer
- ~int * const p = i~: constant pointer to integer

* new & delete
#+begin_src cpp
int *pvalue = new int{5};
delete pvalue;

int *parray = new int[5]{1, 2, 3, 4, 5};
delete[] parray;
#+end_src
