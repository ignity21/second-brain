#+title: Operator Overloading

* Global Functions
- increment: ~int operator++()~, ~int operator++(int)~ (postfix, int is just a dummy)

* In-class Functions
- bool: ~operator bool() const~
- dereference:  ~T& operator*() const~
- pointer: ~T* operator->() const~
- increment: ~T& operator++()~, ~T operator++(int)~
- assignment: ~T& operator=(const T&)~
- type cast: ~operator float() const~, ~operator int() const~, etc.
