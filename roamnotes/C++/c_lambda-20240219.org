#+title: Lambda Functions
#+filetags: C++

* Overview
The runtime effect of a Lambda is the generation of an object, which is known as *closure*. The difference between a Lambda and the corresponding closure is similar to the distinction between a class and an instance of the class.

* ~mutable~
#+begin_src c++
// fn is a closure
auto fn = [id]() mutable {
  std::cout << "ID = " << ++id << std::endl;
};  // OK, captured 'id' may be modified inside the function body
#+end_src
