* Copying Policies
1. Default copying
2. No copying
3. Exclusive ownership (unique_ptr)
4. Deep copying
5. Shared ownership (shared_ptr)

#+begin_src cpp
  // int **XXXCopy::_myInt;

  ExclusiveCopy(ExclusiveCopy &source) {
    _myInt = source._myInt;
    source._myInt = nullptr;
  }

  DeepCopy(DeepCopy &source) {
    _myInt = (int *)malloc(sizeof(int));
    ,*_myInt = *source._myInt;
  }

  int SharedCopy::_cnt = 0;
  SharedCopy::SharedCopy(SharedCopy &source) {
    _myInt = source._myInt;
    ++_cnt;
  }
#+end_src

* Rule of Three
If a class needs to have an overloaded *copy constructor*, *copy assignment operator*, or *destructor*, then it must also implement the other two as well to ensure that memory is managed consistently.
