** Non-virtual Override
#+begin_src cpp
class Base {
public:
  void print() { cout << "Base\n"; }
};

class Derived : public Base {
public:
  void print() { cout << "Derived\n"; }
};

Derived obj;
obj.print(); // Derived
Base *pBase = static_cast<Base *>&obj;
pBase->print() // Base
#+end_src

** Virtual Inheritance
- Virtual inheritance is used to solve the diamond problem
#+begin_example
    Base
   /    \
  /      \
Derived1  Derived2
  \      /
   \    /
    Final
#+end_example
- Without virtual inheritance, Final would inherit two separate copies of Base

** ~override~
- ~override~ is used to indicate that a function is overriding a virtual function in the base class
  - The compiler will check the ~virtual~ function signature
- ~virtual int DoSomething() override {}~

** ~final~
- ~final~ is used to indicate that a virtual function cannot be overridden in derived classes
- ~virtual int DoSomething() override final {}~
