#+title: Special Forms

* Overview
- Special forms are something like built-in macros
  - e.g. ~if~, ~progn~, ~setq!~

* ~let~
#+begin_src elisp
(let ((a 1)
      b
      c
      (d 3))
  (message "a: %s, b: %s, c: %s, d: %s" a b c d))
;; => "a: 1, b: nil, c: nil, d: 3"
#+end_src

* ~save-excursion~
:PROPERTIES:
:ID:       f21f0312-15cd-4a7a-8176-7c89e220f0d3
:END:
1. It *saves the location of point*
2. executes the body of the function
3. then *restores point to its previous position* if its location was changed
#+begin_src elisp
(save-excursion
  body…)
#+end_src
- related functions:
  - ~point~: return the value of the current position
  - ~point-min~, ~point-max~: beginning/end of the buffer
