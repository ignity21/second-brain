* 分类、索引与重名约定

- 一级目录是笔记的主要入口，不是互斥的身份标签；应作为主题的粗粒度分类使用，而非依赖大量 tag。
- 笔记的身份由 UUID v4 的 =:ID:= 和 =[[id:...]]= 链接决定。目录与索引是可重构的导航层：可以移动笔记文件、调整主归属，并在一个或多个中间层级索引中引用同一笔记，而不复制内容。
- 跨目录移动笔记后，检查相对图片链接（如 =[[file:images/...]]= ）是否仍能正确解析。
- 同名但语言或领域不同的笔记，主标题使用可区分的名称，如 =C++ Code Conventions= 与 =Python Code Conventions= ；
  - 在所属中间层级索引中可显示简短链接名 =Code Conventions= 。
- 不要为不同笔记设置相同的 =:ROAM_ALIASES:=。若存在真正跨语言、跨领域的通用主题，单独建立一个主题节点，并由具体笔记链接到它。

* Org-Roam 笔记系统

** 优势
- 熟悉 org-mode 生态
- 数学公式记录方便（LaTeX 原生支持）

** 目录结构方案

*** 已测试方案
- *单目录 + 全靠 tag* ：所有 Note 平铺，依赖 tag 分类
  - 缺点：大知识库下难以管理
- *大类一个目录* ：跨类链接不方便

*** 当前方向（大类子目录）
- 整体单个数据库，按大类建子目录
- 大类目录内部保持扁平，但通过“大类索引 → 中间层级索引 → 具体笔记”构建图谱层级
- 记录时用自定义函数选择目标大类
- Tag 作为补充分类手段
- UI 可按子目录或全库出图
- Node 以文件为单位，文头 =- tags:= 记录关联关系
