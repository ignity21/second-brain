* Schema
- Shape: ~df.shape~
- Column names and dtype: ~df.schema~
- useful if we have many columns: ~df.glimpse()~

* Selection

- By Rows: ~df[0]~, ~df[-1]~, ~df[1:3]~
- By Columns: ~df["region"]~, ~df[["region", "channel"]]~
- By Both (row first, then columns): ~df[:3, ["region", "channel"]]~
- Row Filter: ~df.filter(pl.col("price") < 500)~
  - Useful boolean expressions: ~is_in()~, ~not_()~, ~is_between()~

** ~df.select()~
#+begin_src python
df.select(
    "name",
    (pl.col("price") * 0.8).round(0).alias("discounted_price"), # Chaining
    pl.col("price").mean().alias("average_price"), # Aggregation
    pl.lit(True).alias("available"), # Creating Columns from Constants
    pl.col("price").rank(), # Built-in Functions 
    pl.col("type").str.to_lowercase(), # Data-Type-Specific Expressions
    pl.col("price", "review").min().name.suffix("_min"),
)
#+end_src

** ~pl.selectors~
#+begin_src python
import polars.selectors as cs
df.select(
    # Select the string columns together with the columns ending with "s"
    cs.string() | cs.ends_with("s") 
)
#+end_src

* Editing Columns
** Updating
#+begin_src python
df.with_columns(
    pl.col("price").mean().alias("average_price"),
    pl.col("bedrooms").cast(pl.Int16), # Change data type
)
#+end_src

** Renaming
- ~df.rename({"old": "new"})~

** Deleting
- ~df.drop("review", "beach")~

** Multiple Columns (same expression)
- ~df.with_columns(pl.col("name", "type").str.len_chars())~
- with dtypes: ~df.with_columns(pl.col(pl.String).str.len_chars())~
- Exclude columns: ~df.with_columns(pl.exclude("beach").cast(pl.String))~

* Sorting

- ~df.sort("quantity", descending=True)~ # default ascending
- By multiple columns: ~df.sort("quantity", "product")~

* Summarizing

- Finding extreme values: ~df.top_k(3, by="quantity")~ or ~bottom_k~
- ~df.describe()~

* Lazy Mode
#+begin_src python
pl.scan_csv("data.csv").select("name", "price")

# .collect() actually executes the optimized plan.
#+end_src
