* Schema
- Shape: ~df.shape~

* Selection

- By Rows: ~df[0]~, ~df[-1]~, ~df[1:3]~
- By Columns: ~df["region"]~, ~df[["region", "channel"]]~
- By Both (row first, then columns): ~df[:3, ["region", "channel"]]~
- Row Filter: ~df.filter(pl.col("price") < 500)~
  - Useful boolean expressions: ~is_in()~, ~not_()~, ~is_between()~

** ~df.select()~
#+begin_src python
df.select(
    "name",
    (pl.col("price") * 0.8).round(0).alias("discounted_price"), # Chaining
    pl.col("price").mean().alias("average_price"), # Aggregation
    pl.lit(True).alias("available"), # Creating Columns from Constants
    pl.col("price").rank(), # Built-in Functions 
    pl.col("type").str.to_lowercase(), # Data-Type-Specific Expressions
    pl.col("price", "review").min().name.suffix("_min"),
)
#+end_src

    # Select the string columns together with the columns ending with "s"
    cs.string() | cs.ends_with("s") 
)
#+end_src

** Custom Transformation
#+begin_src python
def rescale_review(x):
    return x * 2

df.with_columns(
    pl.col("review").map_elements(
        rescale_review,
        return_dtype=pl.Float64,
    ).alias("review")
)

# But prefer this:
df.with_columns(
    (pl.col("review") * 2).alias("review")
)
#+end_src
- Use ~map_elements~ when:
  - the logic is easier to express as a Python function
  - performance is not important
  - you need to call a third-party Python function

* Concatenation & Join
** Concatenation
- ~pl.concat([df1, df2], how="vertical")~
| Method     | Direction | Typical use                                  |
|------------+-----------+----------------------------------------------|
| vertical   | Rows      | Combine DataFrames with the same schema      |
| diagonal   | Rows      | Combine DataFrames with different columns    |
| horizontal | Columns   | Add columns                                  |
| extend()   | Rows      | Efficient when adding small batches in place |

** Join
- ~df1.join(df2, on=["key1", "key2"], how="full", coalesce=True)~
  - Use ~coalesce=True~ to avoid duplicate join columns

*** Conditional Join
#+begin_src python
restaurants.join_where(
    users,

    pl.col("price") <= pl.col("budget"),
)
#+end_src

*** Timeseries Conditional Join
- ~join_asof~: means "join as of" a certain date
#+begin_src python
result = trades.sort("time").join_asof(
    quotes.sort("time"),
    on="time",
    strategy="backward",
)
#+end_src
- Strategy:
  - backward: latest matching value before or equal to the left value *It never matches with future data*
  - forward: earliest matching value after or equal to the left value
  - nearest: value with the smallest distance
