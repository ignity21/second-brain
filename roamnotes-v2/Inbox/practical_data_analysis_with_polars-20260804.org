* Missing Values
** Finding nulls
- Count nulls in every column with ~df.null_count()~
- Find rows where a column is null using ~df.filter(pl.col("price").is_null())~

** Removing nulls
- ~df.drop_nulls()~ removes rows containing a null in any column.
- ~df.drop_nulls(subset="singles")~ check only selected columns

** Filling nulls
- ~df.with_columns(pl.col("singles").fill_null(0))~
- ~df.with_columns(pl.col("review").fill_null(pl.col("review").mean()))~

* Duplicates
** Finding Duplicates
- ~df.filter(df.is_duplicated())~: display duplicated rows
- ~df.filter(pl.col("name").is_duplicated())~

** Removing Duplicates
- ~df.unique()~ keeps one copy of each fully duplicated row.
- ~df.unique(subset=["name", "gender"])~

* Value Counts
- ~series.value_counts(sort=True)~

import plotly.express as px

#+end_src
* Grouping and Aggregating
#+begin_src python
df.group_by("type", maintain_order=True).agg(
    pl.col("price").mean()
).sort("price")

df.group_by("type").agg(
    pl.col("price").mean().name.suffix("_mean"),
    pl.col("price").max().name.suffix("_max"),
)

# Grouping by multiple columns
df.group_by("type", "bedrooms").agg(
    pl.col("price").mean(),
    pl.len(), # count rows in group
)
#+end_src

** Lazy Mode Example
#+begin_src python
(
    pl.scan_csv("rentals.csv")
    .group_by("type", "bedrooms")
    .agg(pl.col("price").mean())
    .explain() # .collect()
)

* Pivoting and Unpivoting
** Core Idea

~pivot~ and ~unpivot~ convert data between two common layouts:

#+begin_example
Long format --pivot--> Wide format
Wide format --unpivot--> Long format
#+end_example

Long format: categories are stored as values in a column.
Wide format: categories are spread across multiple columns.

#+begin_quote
Use long format for analysis and wide format for presentation.
#+end_quote

** Pivot

- Turn the unique values of one column into new columns.

*** Before: Long Format

| Month | Product | Sales |
|-------+---------+-------|
| Jan   | Apple   |   100 |
| Jan   | Banana  |    80 |
| Feb   | Apple   |   120 |
| Feb   | Banana  |    90 |

*** After: Wide Format

| Month | Apple | Banana |
|-------+-------+--------|
| Jan   |   100 |     80 |
| Feb   |   120 |     90 |

#+begin_src python
df.pivot(
    on="Product",
    index="Month",
    values="Sales",
    # aggregate_function=...
)
#+end_src

Pivoted data is commonly used for
- reports
- dashboards
- spreadsheets
- comparison tables.

Think of ~pivot~ as expanding categories into columns.

** Unpivot

- Reverse a pivot by collecting multiple columns into rows.

#+begin_src python
df.unpivot(
    on=["Apple", "Banana"],
    index="Month",
    variable_name="Product", 
    value_name="Sales",
)
#+end_src

This converts the data back into long format:

| Month | Product | Sales |
|-------+---------+-------|
| Jan   | Apple   |   100 |
| Jan   | Banana  |    80 |
| Feb   | Apple   |   120 |
| Feb   | Banana  |    90 |

** Summary
~pivot~: categories become columns.
~unpivot~: columns become category values.

*** Long Format is Usually Better for
- Filtering
- Grouping
- Aggregation
- Visualization
- Statistical analysis
- Machine learning
  
*** Wide Format is Usually Better for
- Reports
- Spreadsheets
- Dashboards
- Pivot tables
- Human-readable comparisons
