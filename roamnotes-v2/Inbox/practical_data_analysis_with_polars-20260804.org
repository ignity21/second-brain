* Missing Values
** Finding nulls
- Count nulls in every column with ~df.null_count()~
- Find rows where a column is null using ~df.filter(pl.col("price").is_null())~

** Removing nulls
- ~df.drop_nulls()~ removes rows containing a null in any column.
- ~df.drop_nulls(subset="singles")~ check only selected columns

** Filling nulls
- ~df.with_columns(pl.col("singles").fill_null(0))~
- ~df.with_columns(pl.col("review").fill_null(pl.col("review").mean()))~

* Duplicates
** Finding Duplicates
- ~df.filter(df.is_duplicated())~: display duplicated rows
- ~df.filter(pl.col("name").is_duplicated())~

** Removing Duplicates
- ~df.unique()~ keeps one copy of each fully duplicated row.
- ~df.unique(subset=["name", "gender"])~

* Grouping and Aggregating

    pl.col("price").mean()
).sort("price")

* Pivoting and Unpivoting
** Core Idea

~pivot~ and ~unpivot~ convert data between two common layouts:

#+begin_example
Long format --pivot--> Wide format
Wide format --unpivot--> Long format
#+end_example

Long format: categories are stored as values in a column.
Wide format: categories are spread across multiple columns.

#+begin_quote
Use long format for analysis and wide format for presentation.
#+end_quote

** Pivot

- Turn the unique values of one column into new columns.

*** Before: Long Format

| Month | Product | Sales |
|-------+---------+-------|
| Jan   | Apple   |   100 |
| Jan   | Banana  |    80 |
| Feb   | Apple   |   120 |
| Feb   | Banana  |    90 |

*** After: Wide Format

| Month | Apple | Banana |
|-------+-------+--------|
| Jan   |   100 |     80 |
| Feb   |   120 |     90 |

#+begin_src python
df.pivot(
    on="Product",
    index="Month",
    values="Sales",
    # aggregate_function=...
)
#+end_src

Pivoted data is commonly used for
- reports
- dashboards
- spreadsheets
- comparison tables.

Think of ~pivot~ as expanding categories into columns.

** Unpivot

- Reverse a pivot by collecting multiple columns into rows.

#+begin_src python
df.unpivot(
    on=["Apple", "Banana"],
    index="Month",
    variable_name="Product", 
    value_name="Sales",
)
#+end_src

This converts the data back into long format:

| Month | Product | Sales |
|-------+---------+-------|
| Jan   | Apple   |   100 |
| Jan   | Banana  |    80 |
| Feb   | Apple   |   120 |
| Feb   | Banana  |    90 |

** Summary
~pivot~: categories become columns.
~unpivot~: columns become category values.

*** Long Format is Usually Better for
- Filtering
- Grouping
- Aggregation
- Visualization
- Statistical analysis
- Machine learning
  
*** Wide Format is Usually Better for
- Reports
- Spreadsheets
- Dashboards
- Pivot tables
- Human-readable comparisons
* Text Transformation
** Casting Data Type
  - ~df.with_columns(pl.col("rating").cast(pl.Int64))~
  - Cast multiple column types: ~df.cast({pl.Float64: pl.Int64})~

** Cleaning Text
- String operations are available through the ~.str~ namespace.
  - ~df.with_columns(pl.col("business").str.strip_chars_start())~

** Creating an Unique Identifier
#+begin_src python
df.with_columns(
    pl.concat_str(
        "business",
        "location",
        separator=", "
    ).alias("id")
)
#+end_src

** Searching Text

~str.contains()~ checks whether each string contains a matching pattern.
The pattern is case-sensitive by default.

#+begin_src python
rating.with_columns(
    pl.col("business")
    .str.contains("Burger")
    .alias("is_burger"),

    pl.col("business")
    .str.to_lowercase()
    .str.contains("burger")
    .alias("is_burger_case_insensitive"),
)
#+end_src

- ~"Burger"~ only matches text with the same capitalization.
- For case-insensitive matching, convert both the text and the search pattern to lowercase.
- ~str.contains()~ treats its argument as a regular expression by default.

** Extracting Text

~str.extract()~ extracts text matched by a regular-expression capture group.

#+begin_src python
rating.with_columns(
    pl.col("business")
    .str.extract(r"(burger|coffee)")
    .alias("food"),
)
#+end_src

- ~(burger|coffee)~ is a regular expression.
- Parentheses define the capture group to extract.
- Rows without a match return ~null~.

** Filtering Text Matches

Use ~filter()~ with ~str.contains()~ to keep only rows whose text matches the pattern.

#+begin_src python
ratings.filter(
    pl.col("business")
    .str.to_lowercase()
    .str.contains("burger")
)
#+end_src

** Replacing Text
#+begin_src python
df.with_columns(
    pl.col("location")
    .str.replace("Rd.", "Road"),
    # or replacing multiple strings
    pl.col("location")
    .str.replace_many(["Rd.", "St."], ["Road", "Street"]),
)
#+end_src
