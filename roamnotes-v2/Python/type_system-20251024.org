#+title: Python Type System

* Alias
#+begin_src python

type MyTuple = tuple[int, ...] # Variable-length tuple of integers

# built-in types
type tuple = Tuple[Any, ...]

* NewType
#+begin_src python
from typing import NewType

    ...
user_a = get_user_name(UserId(42351))

* Callable
#+begin_src python
from collections.abc import Callable, Awaitable
# from typing import Callable -> deprecated in Python 3.12
type Function = Callable[[int, str], float]
type AsyncFunction = Callable[[int, str], Awaitable[float]]
x: Callable[..., str] # A function that takes any number of arguments and returns a string
#+end_src

- Callable cannot express complex signatures such as
  - *functions that take a variadic number of arguments*
  - *overloaded functions*
  - *functions that have keyword-only parameters*
  - Solution: using ~Protocol~

** Protocol
#+begin_src python
from typing import Protocol

from collections.abc import Iterable
from typing import Protocol

class Combiner(Protocol):
    def __call__(self, *vals: bytes, maxlen: int | None = None) -> list[bytes]: ...

def batch_proc(data: Iterable[bytes], cb_results: Combiner) -> bytes:
    for item in data:
        ...

def good_cb(*vals: bytes, maxlen: int | None = None) -> list[bytes]:
    ...
def bad_cb(*vals: bytes, maxitems: int | None) -> list[bytes]:
    ...

batch_proc([], good_cb)  # OK
batch_proc([], bad_cb)   # Error! Argument 2 has incompatible type deferent name
#+end_src

* Generators and Coroutines
** Generators
- ~Generator[YieldType, SendType, ReturnType]~
  - ~SendType, ReturnType~ default to ~types.NontType~
  - ~Generator[int]~ = ~Generator[int, None, None]~
- Simple generators that only ever yield values can also be annotated as
  - ~Iterable[YieldType]~
  - ~Iterator[YieldType]~
#+begin_src python
from collections.abc import Generator

def echo_round() -> Generator[int, float, str]:
    sent: float = yield 0
    while sent >= 0:
        sent = yield round(sent)
    return 'Done'
#+end_src
- ~AsyncGenerator[YieldType, SendType]~
  - Don't expect a ~ReturnType~ type argument
  - ~AsyncIterable[YieldType]~
  - ~AsyncIterator[YieldType]~

** Coroutines
- ~Coroutine[YieldType, SendType, ReturnType]~
#+begin_src python
from collections.abc import Coroutine
c: Coroutine[list[str], str, int]  # Some coroutine defined elsewhere
x = c.send('hi')                   # Inferred type of 'x' is list[str]
async def bar() -> None:
    y = await c                    # Inferred type of 'y' is int
#+end_src

** Bounded Type
#+begin_src python
# for Python 3.13+
class Sequence[T]:
    ...

class StrSequence[T: str]:
    ...

class StrOrBytesSequence[T: str | bytes]:
    ...

# legacy way for Python 3.9+
from typing import Generic, TypeVar
