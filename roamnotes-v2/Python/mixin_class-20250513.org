#+title: Mixin Class
#+filetags: :OO:

* 概述
- Mixin 把额外的功能“混入”某个类
- Python 中使用多重继承来实现 Mixin 模式

* 例子
- 类名以 Mixin 结尾作为惯例
- Mixin 类通常很简单，实现单一功能
- Mixin 设计初衷是为糟糕的模型设计做一些廉价的弥补
#+begin_src python :results output
class InfoDumperMixin:
    def dump_info(self):
        d = self.__dict__
        print(f"Numberof members: {len(d)}")
        for key, value in d.items():
            print(f"- {key}: {value}")

class Person(InfoDumperMixin):
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Alice", 30)
p.dump_info()
#+end_src
