* Python Interpreter
- ~uv python list~ shows the list of all available Python interpreters.
- ~uv python install 3.8 3.11~
- ~uv python install pypy@3.10~
- ~uv python uninstall 3.11~
- ~uv python pin pypy~: Pin the current project to use a specific Python version using =.python-version= file.
- ~uv python dir~: Show the directory where Python interpreters are installed.

* Projects
** Work Flow
1. ~uv init -p [MINIMUN]~
2. ~uv add (--dev) [PACKAGES]~
3. ~uv venv -p [PYTHON]~, ~uv lock~, ~uv sync~
4. ~source .venv/bin/activate~
5. ~uv pip install -e .~

** Commands
Replaces ~poetry~
- ~uv init~: Create a new Python project.
- ~uv venv -p 3.8~: Create a new virtual environment for the project.
- ~uv add~: Add a dependency to the project.
- ~uv remove~: Remove a dependency from the project.
- ~uv sync~: Sync the project's dependencies with the environment.
- ~uv lock~: Create a lockfile for the project's dependencies.
- ~uv run~: Run a command in the project environment.
- ~uv tree~: View the dependency tree for the project.
- ~uv build~: Build the project into distribution archives.
- ~uv publish~: Publish the project to a package index.

** Dependencies
#+begin_src bash
uv add requests
uv add 'requests==2.31.0'
uv add git+https://github.com/psf/requests
uv add -r requirements.txt -c constraints.txt
uv remove requests

# Upgrade a package
uv lock --upgrade-package requests
#+end_src

** Example
#+begin_src bash
uv init hello-world
# or
mkdir hello-world
cd hello-world
uv init
uv add flask
# or uv add git+https://github.com/psf/requests
uv run -- flask run -p 3000
uv run main.py
#+end_src
- =.python-version=: the project's default Python version.
- =.venv=: contains your project's virtual environment.
- =uv.lock=: is a cross-platform lockfile that contains exact information about your project's dependencies.

* ~uv tool~
Replaces ~pipx~
- ~uvx~ / ~uv tool run~: Run a tool in a temporary environment.
- ~uv tool install~: Install a tool user-wide.
- ~uv tool uninstall~: Uninstall a tool.
- ~uv tool list~: List installed tools.
- ~uv tool update-shell~: Update the shell to include tool executables.
- ~uv tool dir~: Show the directory where tools are installed.
- replace ~pipx inject~
  - ~pipx inject aider-chat google-generativeai~
  - ~uv tool run --from aider-chat pip install google-generativeai~
