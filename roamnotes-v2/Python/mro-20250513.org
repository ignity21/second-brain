#+title: MRO
#+filetags: :OO:

* Overview
- Method resolution order
- 解决多重继承优先级问题
- ~super()~ 也使用 MRO 找基类方法

* Examples
** Multiple Inheritance
#+begin_src python :results output
class A:
    def method(self):
        print("A.method()")

class B(A):
    pass

class C(A):
    def method(self):
        print("C.method()")

class D(B, C):
    pass

print(D.mro())
d = D()
d.method()
#+end_src

#+RESULTS:
: [<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>]
: C.method()

** ~super()~
- ~super()~ 使用的是 MRO 链条里的上一个类
#+begin_src python :results output
class A:
    def __init__(self):
        print("A.__init__()")
        super().__init__()

class B(A):
    def __init__(self):
        print("B.__init__()")
        super().__init__()

class C(A):
    def __init__(self):
        print("C.__init__()")
        super().__init__()

class D(B, C):
    pass

print(D.mro())
d = D()
#+end_src

#+RESULTS:
: [<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>]
: B.__init__()
: C.__init__()
: A.__init__()
