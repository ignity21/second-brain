* Overview
* 组件
** 窗体组件
- Main Window: 具备主窗体的特性，如菜单栏、工具栏、状态栏等
- Dialog: 一般对话框，可以模态显示、有返回值等
- Widget: 界面组件，如 ~QLable~, ~QPushButton~
  - ~QWidget~ 是所有组件的父类，也包括 ~QMainWindow~ 和 ~QDialog~
  - ~QWidget~ 可以作为独立的窗口运行

* Qt Modules
- ~QtCore~: 提供核心的非 GUI 功能的类，常用命名空间 ~Qt~ ；常用 ~pyqtSlot~, ~pyQtSignal~
- ~QtGui~: 提供 GUI 设计中用到的功能性的类，如 ~QFont~, ~QIcon~, ~QCloseEvent~
- ~QtWidgets~
- ~QtMultimedia~
- ~QtMultimediaWidgets~

* QEvent
** 接口函数
- ~accept()~: 表示接受此事件，不再向上传播
- ~ignore()~: 忽略事件，向上传播
- ~type()~: 返回事件类型

** 事件处理流程
1. 收到操作系统事件
2. 传入 ~QObject~ 的 ~event(self, e)~ 函数进行处理
3. 分派到具体处理函数，如： ~mouseDoubleClickEvent()~
4. 处理函数中触发信号 ~qtsingal.emit()~ (signal 是对事件的封装)
