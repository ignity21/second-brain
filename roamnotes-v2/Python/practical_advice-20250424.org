* 循环
** 迭代器和可迭代对象
*** Iterable 接口
- ~__iter__~: 返回一个迭代器
- ~__getitem__~: 即使没有实现 ~__iter__~ 也是可迭代的，根据下标遍历，直到抛出 IndexError 为止

*** Iterator 接口
- ~__iter__~: ~return self~
- ~__next__~: return 返回每次迭代结果，抛出 StopIteration 退出循环

** ~itertools~
- ~product()~: 替代多层嵌套循环 ~for i, j, k in product(X, Y, Z)~
- ~islice(start, stop, step)~: 实现循环隔行处理
  - for 循环用于文件对象上，会进行逐行遍历，可使用 ~islice~ 实现每隔 n 行处理
- ~takewhile(pred, iterable)~: 替代 ~break~ 语句

** ~iter(callable, sentinel)~
- 代替 ~while True~ 循环
#+begin_src python
def count_digit(fpath):
    count = 0
    with open(fpath, 'r') as f:
        block_size = 1024
        while True:
            block = f.read(block_size)
            # block == '' means EOF
            if not block:
                break
            for char in block:
                if char.isdigit():
                    count += 1
    return count

from functools import partial
def count_digit_revised(fpath):
    count = 0
    block_size = 1024
    with open(fpath, 'r') as f:
        _read = partial(f.read, block_size)
        for block in iter(_read, ''):
            for char in block:
                if char.isdigit():
                    count += 1
    return count
#+end_src

class ignore_closed:
    def __enter__(self):
        pass

    def __exit__(self, exc_type, exc_value, traceback):
        if exc_type == AlreadyClosedError:
            return True # Suppress the exception, won't raise it
        return False # Raise other exceptions

with ignore_closed():
    close_conn(conn)

*** 使用 ~contextmanager~ 简化上下文管理器
#+begin_src python
from contextlib import contextmanager

@contextmanager
def create_conn_obj(host, port, timeout=None):
    conn = create_conn(host, port, timeout)
    try:
        # before yield: __enter__ end
        yield conn
        # after yield: __exit__ begin
    finally:
        conn.close()
#+end_src
- 必须用 ~try~ 包裹 ~yield~ 语句来处理异常

** 浅装饰器，深实现

  - 内部逻辑应该简单，复杂逻辑需要封装

* 类
** 类方法和类静态方法的区别
- 类方法第一个参数是类本身 ~cls~ ，函数内可以使用该类对象
- 类静态方法无须传入类对象或实例对象
  - 内部逻辑不需要访问类对象或实例对象
  - 类和实例方法都可以调用类静态方法

** 类静态方法和普通函数的考量
- 类作为命名空间使用
- 当类静态方法与类 *关系密切* 时，使用类静态方法
- 类静态方法可以被继承和重写
