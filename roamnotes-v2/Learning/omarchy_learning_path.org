#+title: Omarchy Learning Path
#+filetags: :learning:Linux:Tools:

开始于 2026-11-10。主线：在 Omarchy 上把桌面和开发环境用顺手——窗口怎么摆、配置改哪里、改坏了怎么回来、开发工具的版本由谁管。目标是「知道」（见 learning-goals）：常用窗口键形成肌肉记忆，其余知道去哪查。

不少步骤要在电脑前动手，手机上可以先读笔记、想好核心问题，回到电脑再练。「待补」是笔记还缺、用的时候再补的内容。

* 2. 窗口操作 [0/3]
- [ ] [[id:8f59c6ed-ec02-4dbf-90ab-2463e4f7dd10][Omarchy]] 的「Hyprland 怎么摆窗口」：为什么每开一个应用就多一块平铺区域？哪些窗口会浮动、由什么决定？平铺 WM 里没有最小化，用什么代替？
- [ ] [[id:8f59c6ed-ec02-4dbf-90ab-2463e4f7dd10][Omarchy]] 的「窗口操作常用键」：在电脑前练，目标是不看表完成：关窗口、平铺 ↔ 浮动、切工作区并把窗口移过去、scratchpad 收起和呼出、分组。每天用几次，比一次背完有效。
- [ ] [[id:8f59c6ed-ec02-4dbf-90ab-2463e4f7dd10][Omarchy]] 的「待试的窗口工作流」：实际试一遍 1Password 挡输入框、LazyCat 开出多个平铺窗口这两个问题的候选做法，把选定的做法写进 My Take。

Anki：Omarchy 里暂时收起窗口。
