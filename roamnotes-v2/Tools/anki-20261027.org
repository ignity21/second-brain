#+title: Anki Card Writing and Templates
#+filetags: :Tools:

* Writing Cards
- *Keep it simple*: the shorter the card, the easier the review. This is rule 4 of SuperMemo's "Effective learning: Twenty rules of formulating knowledge", the *minimum information principle*.
- *Don't memorize without understanding*: learn in context, for example words inside sentences.
- *Prefer cloze deletion* for facts in context (rule 5): ~{{c1::Canberra::city}} was founded in 1913.~ shows =[city] was founded in 1913.= ; the text after the second ~::~ is the hint.
- An easy question is not a good one: the easier a card makes recalling the answer, the less likely you are to recall it in real life without the card's cues.

This repository's own card rules are in the =anki-cards= skill.

* Template Capability Map
| Need | Template syntax |
|---|---|
| Show a hint behind a click, only if the field is filled | ~{{hint:MyField}}~ |
| A field without HTML formatting (e.g. in a URL) | ~{{text:Front}}~ , as in ~<a href="https://example.com/search?q={{text:Front}}">dictionary</a>~ |
| Ruby annotations for Japanese | Field text ~日本語[にほんご]~ ; template ~{{furigana:MyField}}~ (both), ~{{kana:MyField}}~ , ~{{kanji:MyField}}~ |
| Type the answer and check it | ~{{type:Text}}~ ; for cloze ~{{cloze:Text}}~ plus ~{{type:cloze:Text}}~ |
| Show something only if a field is filled / empty | ~{{#Field}}...{{/Field}}~ / ~{{^Field}}...{{/Field}}~ , e.g. a "Tags:" label shown only when there are tags |
| Built-in fields | ~{{Tags}}~ , ~{{Type}}~ , ~{{Deck}}~ , ~{{Subdeck}}~ , ~{{CardFlag}}~ , ~{{Card}}~ , ~{{FrontSide}}~ |

* Styling Capability Map
Card styles are CSS on the note type:
| Need | CSS |
|---|---|
| Base style | ~.card { font-family: arial; font-size: 20px; text-align: center; }~ |
| Keep large images at full size | ~img { max-width: none; max-height: none; }~ |
| Style one field | Wrap it: ~<div class=mystyle1>{{MyField}}</div>~ , then style ~.mystyle1~ |
| Night mode | ~.card.nightMode { ... }~ , ~.nightMode .myclass { ... }~ |
| Audio replay buttons | ~.replay-button svg { width: 20px; height: 20px; }~ |
| Per platform | Classes on the card: ~.win~ , ~.mac~ , ~.linux:not(.android)~ , ~.mobile~ , ~.iphone~ , ~.ipad~ , ~.android~ |

Fonts can be installed into the collection's media folder (Anki manual, "Styling & HTML").
