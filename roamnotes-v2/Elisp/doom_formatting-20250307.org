#+title: Formatting in Doom Emacs

* Overview
- ~+format-with~: decide which formatter will be used.
  - e.g. ~(setq-hook! 'python-mode-hook +format-with 'black)~
- ~(set-formatter!)~
#+begin_src elisp
 (after! dockerfile-mode
   (set-formatter! 'dockfmt '("dockfmt" "fmt" filepath) :modes '(dockerfile-mode)))
#+end_src
