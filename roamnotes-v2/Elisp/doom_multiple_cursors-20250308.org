#+title: Multiple Cursors in Doom Emacs

* Overview
- To get out of multiple-cursors-mode, press =<return>= or =C-g=
- Insert a newline in multiple-cursors-mode, use =C-j=

* Key Bindings
| Key         | Description                  |
|-------------+------------------------------|
| =C-c e m p= | Mark previous line like this |
| =C-c e m n= | Mark next line like this     |
| =C-c e m a= | Mark all like this           |
| =C-c e m e= | Edit lines                   |

- ~prog-mode-map~
| Key         | Description                  |
|-------------+------------------------------|
| =C-<right>= | Mark previous line like this |
| =C-<left>=  | Mark next line like this     |
