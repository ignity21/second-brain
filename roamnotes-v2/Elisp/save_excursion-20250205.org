#+title: ~save-excursion~

* Overview
1. It *saves the location of point*
2. executes the body of the function
3. then *restores point to its previous position* if its location was changed
#+begin_src elisp
(save-excursion
  body…)
#+end_src
- related functions:
  - ~point~: return the value of the current position
  - ~point-min~, ~point-max~: beginning/end of the buffer
