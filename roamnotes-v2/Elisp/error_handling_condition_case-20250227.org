#+title: Error Handling with ~condition-case~

* Overview
Just like try...catch...
#+begin_src elisp
(condition-case
  var ; is sometimes bound to a variable that contains information about the error, can be nil
  bodyform ; what should happen when everything works correctly
  error-handler…
  )
#+end_src
- An *error-handler* has two parts, a *condition-name* and a body
  - If condition-name matches a name generated by an error
  - the body part of the error handler is run
- Complete condition-case expression may contain more than one error handler
