* Overview
- =packages.el= declare all the packages it will install
- =config.el= configure and load those packages
- =autoload.el= to store that module's functions
- [[https://github.com/doomemacs/doomemacs/blob/master/modules/completion/company/README.org][e.g. :completion company]]

* Files
** =init.el=
This file is loaded early, before anything else, but after Doom core is loaded.

Do:
- Configure Emacs or perform setup/teardown operations that must be set early
- *Reconfigure packages defined in Doom modules* with ~use-package-hook!~

** =config.el=
Do:
- Use ~after!~ or ~use-package!~ to configure packages
- Lazy load packages with use-package's ~:defer~ property
- Use the featurep! macro to make some configuration conditional

Don't:
- Install packages with use-package's ~:ensure~ property.

** =packages.el=
Do:
- Declare packages with the ~package!~ macro
- Disable packages with package!'s ~:disable~ or ~disable-packages!~ macro
- Use the ~featurep!~ macro to make packages conditional

** =autoload.el= or =autoload/*.el=
- Place cookie ~;;;###autoload~ on top of a lisp form will do one of two things:
  - Add a autoload call to Doom's autoload file(=~/.emacs.d/.local/autoloads.el=)
  - Doom's autoload file is generated when you execute ~doom sync~

** =doctor.el=
- Check if the module's dependencies are satisfied
- Use the ~warn!~, ~error!~ and ~explain!~ to communicate issues to the user

** =cli.el=
- Use it to define your own CLI commands or reconfigure existing ones. ~doom command~

** =test/**/test-*.el=
- Doom's unit tests

* Cookies
** ~;;;###if~
Any file in a module can have a ~;;;###if FORM~ at the top of the file
- FORM is evaluated to determine whether or not to include this file for:
  - autoloads scanning ~doom sync~
  - byte-compilation ~doom compile~
- Examples:
#+begin_src elisp
;;;###if (featurep! +particular-flag)
;;;###if (not (locate-library "so-long"))
#+end_src

** ~;;;###package~
- This cookie exists solely to assist the ~doom/help-packages~ command
- ~doom/help-packages~ command scanning for
  - ~package!~, ~after!~, ~use-package!~, ~use-package~
  - or ~;;;###package package-name~

** ~;;;###autodef~
- An ~autodef~ is a special kind of autoloaded function (or macro) which Doom guarantees will always be defined
  - whether or not its containing module is enabled
- Use ~doom/help-autodefs~ to browse the available autodefs
