* Variables
- ~setq~
- ~setq-default~ sets values only in buffers that do not have their own local values for the variable.
- ~defvar~
- ~defcustom~

* Customizable Variables
** ~defcustom~
Arguments
1. variable #+name:

2. initial value, this value is set only if the value has not already been set
3. documentation
4. types, options and group (not featured in ~defvar~)
#+begin_src elisp
(defcustom text-mode-hook nil
  "Normal hook run when entering Text mode and many related modes."
  :type 'hook
  :options '(turn-on-auto-fill flyspell-mode)
  :group 'wp)
#+end_src
- The ~:type~ keyword tells Emacs the kind of data to which text-mode-hook should be set
- The ~:options~ keyword specifies a suggested list of values for the variable

** Customize It
1. ~M-x customize~
2. ~custom-set-variables~

* Autoloading
#+begin_src elisp
(autoload 'html-helper-mode
  "html-helper-mode" "Edit HTML documents" t)
#+end_src
- This expression autoloads the ~html-helper-mode~ function.
- It takes it from the ==html-helper-mode.el/elc= file
  - The file must be located in a directory specified by load-path
- interactive -> t
