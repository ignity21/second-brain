#+title: ELisp Special Forms

* Overview
- Special forms are something like built-in macros
  - e.g. ~if~, ~progn~, ~setq!~

* ~let~
#+begin_src elisp
(let ((a 1)
      b
      c
      (d 3))
  (message "a: %s, b: %s, c: %s, d: %s" a b c d))
;; => "a: 1, b: nil, c: nil, d: 3"
#+end_src

** ~let*~
Variables in the latter part of the varlist can make use of the values to which Emacs set variables earlier in the varlist.
#+begin_src elisp
(let* ((append-to (get-buffer-create buffer))
       (windows (get-buffer-window-list append-to t t)) ; use append-to
       point)
  BODY...)
#+end_src
