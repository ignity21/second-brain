#+title: File Templates in Doom Emacs

* Overview
- Use ~set-file-template!~ to add new or change existing one.
- File template usually starts with =__=
  - Just check the doom =file-templates/config.el=
- Insert licenses: ~(+file-templates/insert-license)~
