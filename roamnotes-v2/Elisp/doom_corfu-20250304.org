#+title: Corfu

* Keybindings
- ~corfu-map~
| Keybinding | Description              |
|------------+--------------------------|
| C-c C-e    | export to minibuffer     |
| C-SPC      | insert space (orderless) |

- ~corfu-popupinfo-map~
| Keybinding | Description       |
|------------+-------------------|
| M-p        | scroll down       |
| M-n        | scroll up         |
| M-<        | move to beginning |
| M->        | move to end       |
| M-t        | toggle popupinfo  |

* Adding CAPFs
#+begin_src elisp
(add-hook! some-mode (add-hook 'completion-at-point-functions #'some-capf depth t))

;; add CAPFs to keys
(map! :map some-mode-map
      "C-x e" #'cape-emoji)
#+end_src

- DEPTH above is an integer between -100, 100, default 0
