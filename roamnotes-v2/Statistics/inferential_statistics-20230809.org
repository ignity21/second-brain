#+title: Inferential Statistics
#+filetags: :Math:Statistics:

* Implications
- Clinical research
- A/B testing
- Feature selection in ML

* Statistic Symbols
| $\mu$          | population mean(expected value) |
| $\sigma$          | population standard deviation   |
| $\hat\mu$    | estimated population mean       |
| $\hat\sigma$ | estimated population sd         |
| $\bar{X_i}$  | one sample $X_i$'s mean         |
| $s$          | sample sd                       |
| $n$          | sample size                     |

* From Sample to Population
- 推断的依据是统计量的抽样分布：[[id:4514ee9e-86ef-4f32-bfc3-151320f23d97][Sampling Distribution]]；样本量够大时由 [[id:193270c8-6738-48fb-b728-8462f10de3c5][Central Limit Theorem]] 近似为正态
- 估计总体参数的范围用 [[id:fd7b8935-0094-403b-ac49-a61c8df0a733][Confidence Intervals]]，判断差异是否显著用 [[id:61297403-6903-4513-90c7-2b5fc0b49e11][Hypothesis Testing]]
- 抽样数据的收集方式见 [[id:889cc76c-cbfa-4f3a-b4c7-7ba4acaaf8e6][Statistic Experiments]]
