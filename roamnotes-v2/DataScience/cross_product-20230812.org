#+title: Cross Product
#+filetags: :LinearAlgebra:

* Definition
Given two *linearly independent* vectors, the *cross product* $\bm{a}\times \bm{b}$ is a vector that is *perpendicular* to both *a* and *b*.
[[file:../assets/Math/CrossProductRightHandRule.png]]

* Code
#+begin_src python
  v1 = [1, 1, 3]
  v2 = [1, 2, 4]
  v3 = np.cross(v1, v2)  # v3 is a vector perpendicular to both v1 and v2 (right-hand rule)
#+end_src
