#+title: Greedy Algorithms
#+filetags: :Algorithms:

* Recognition
- 问题形如「在满足 *限制值* 的情况下，让 *期望值* 最大（或最小）」，而且每一步的局部最优选择不会影响之后能做的选择 → 先考虑贪心。
- 区间调度、区间合并、跳跃游戏、分配饼干、加油站、哈夫曼编码。

* Core Idea
每一步都选对期望值贡献最大的那个，不回头、不考虑以后。

贪心 *不总能* 给出最优解，用之前要说明为什么局部最优能推出全局最优。面试中常用的论证方法是 *交换论证* ：假设某个最优解在第一步没有做贪心选择，把它的第一步换成贪心选择，结果不会变差，所以存在一个以贪心选择开头的最优解；对剩下的子问题重复同样的论证。

反例：硬币面值 [1, 3, 4]，凑 6。贪心先拿最大的 4，再拿 1、1，共 3 枚；最优是 3 + 3，2 枚。这类问题要用动态规划。人民币、美元这样的面值体系贪心恰好正确，不能推广到任意面值。

def max_non_overlapping(intervals):
    """最多能选出多少个互不重叠的区间（LT435 的另一面）。按结束时间贪心。"""
    count, end = 0, float("-inf")
    for s, e in sorted(intervals, key=lambda x: x[1]):
        if s >= end:                 # 与已选区间不重叠
            count, end = count + 1, e
    return count

def greedy_coins(coins, amount):
    n = 0
    for c in sorted(coins, reverse=True):
        n += amount // c
        amount %= c
    return n if amount == 0 else -1

assert max_non_overlapping([[1, 2], [2, 3], [3, 4], [1, 3]]) == 3
assert max_non_overlapping([]) == 0
assert greedy_coins([1, 3, 4], 6) == 3       # 贪心不是最优：3 + 3 只要 2 枚
print("ok")

按 *结束时间* 排序的理由（交换论证）：结束最早的区间给剩下的区间留出最多空间。按开始时间或区间长度排序都有反例。
