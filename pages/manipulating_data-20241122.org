#+title: Manipulating Numerical Data
#+filetags: :Python:DataScience:

* Converting Strings to Numbers
- ~df.transform()~ : Specifically designed to transform data while preserving the original shape of the DataFrame.
#+begin_src python
# Currency(CNY)
# '123,580.00' -> 123580.00
salary["salary"] = salary["salary"].str.replace(",", "").astype(float)
salary["salary_USD"] = salary["salary"] / 7.2
#+end_src

* Summarize Numerical Data by Group
#+begin_src python
planes["airline_price_std"] = planes.groupby("Airline")["Price"].transform(
    lambda x: x.std()) # or "std"

print(planes[["Airline", "airline_price_std"]].value_counts())
#+end_src
