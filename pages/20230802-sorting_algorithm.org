* 总结表
| 算法      | 时间                 | 稳定？ | 原地？ |
|-----------+----------------------+--------+--------|
| Bubble    | $O(n^2)$             | 是     | 是     |
| Insertion | $O(n^2)$             | 是     | 是     |
| Selection | $O(n^2)$             | 否     | 是     |
| Quick     | $O(n\log(n))$        | 否     | 是     |
| Merge     | $O(n\log(n))$        | 是     | 否     |
| Bucket    | $O(n)$               | 是     | 否     |
| Counting  | $O(n+k)$ k为数据范围 | 是     | 是     |
| Radix     | $O(dn)$ d为维度      | 是     | 是     |

* Bubble Sort
:PROPERTIES:
:ID:       a7cea3ae-1bc5-427f-9f09-e42bfac1e28f
:END:
- 优化：一次冒泡过程没有元素交换则已排序完毕

* Insertion Sort
:PROPERTIES:
:ID:       553a8e95-9b74-411b-9fc2-7760ba33f10a
:END:
- 排序已经排好序的集合，复杂度 $O(n)$

* Selection Sort
:PROPERTIES:
:ID:       1fc3f569-5863-4614-9617-9bcf50ba40ef
:END:
与插入排序类似，区别在于从未排序区间找到最小元素放到已排序区间的末端
