#+title: Sorting Algorithm
#+filetags: Algorithm

* 总结表
| 算法      | 时间                 | 稳定？ | 原地？ |
|-----------+----------------------+--------+--------|
| Bubble    | $O(n^2)$             | 是     | 是     |
| Insertion | $O(n^2)$             | 是     | 是     |
| Selection | $O(n^2)$             | 否     | 是     |
| Quick     | $O(n\log(n))$        | 否     | 是     |
| Merge     | $O(n\log(n))$        | 是     | 否     |

* Bubble Sort
:PROPERTIES:
:ID:       a7cea3ae-1bc5-427f-9f09-e42bfac1e28f
:END:
- 优化：一次冒泡过程没有元素交换则已排序完毕

* Insertion Sort
:PROPERTIES:
:ID:       553a8e95-9b74-411b-9fc2-7760ba33f10a
:END:
- 排序已经排好序的集合，复杂度 $O(n)$

* Selection Sort
:PROPERTIES:
:ID:       1fc3f569-5863-4614-9617-9bcf50ba40ef
:END:
与插入排序类似，区别在于从未排序区间找到最小元素放到已排序区间的末端

* Linear Sort
:PROPERTIES:
:ID:       402f4800-7f49-45eb-9a69-4337b220928e
:END:
不涉及比较操作，对排序数据有要求。线性排序有三种：

| Algorithm     | Time     | Space    | Stability | Description                            |
|---------------+----------+----------+-----------+----------------------------------------|
| [[id:7e5829ad-f60e-41ce-8fb8-98a56592aa81][Bucket Sort]]   | $O(n+m)$ | $O(n+m)$ | Yes       | m is the number of buckets             |
| [[id:1776ad9d-bc42-4d0c-b49d-e24f32bff80d][Counting Sort]] | $O(n+k)$ | $O(n+k)$ | Yes       | k is the max value                     |
| [[id:4fd9dbf1-7420-4b4e-86ee-d73bd2055497][Radix Sort]]    | $O(dn)$  | $O(d)$   | Yes       | d is the number of digits of max value |
| [[id:cb0bae70-cb35-4b8d-b6ed-6a00ca472f68][Shell Sort]]    | $O(nh)$  | $O(1)$   | No        | h is the increment sequence            |
