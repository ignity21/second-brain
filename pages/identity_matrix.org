#+TITLE: Identity Matrix
#+filetags: :Linear Algebra

* Definition
The identity matrix is the $n\times n$ square matrix with ones on the main diagonal and zeros elsewhere.
#+begin_src python
  np.diag([1,1,1,...])
  np.identity(n=5)
#+end_src

* Properties
When $A$ is an $m\times n$ matrix,
\[I_m\cdot A=A \cdot I_n=A\]
