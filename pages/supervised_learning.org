#+TITLE: Supervised Learning

- tags :: [[id:9d343f34-3ee6-4737-8612-6718f77dba03][Machine Learning]]


In supervised learning, we are given a data set and already *know what our correct output should look like*,
having the idea that there is a *relationship* between the input and the output.

[[../assets/ML/SupervisedLearning_1.png]]

- [[id:4d9aa428-be23-4297-b24f-6f5d05f565f4][Regression Problem]]: Predict a *continuous* output.
- [[id:e0e88d4d-69d2-4e20-be4c-5aa8b849e968][Classification Problem]]: Predict a *discrete* output.


* Examples
- Regression Problem: Given data about the size of houses on the real estate market, try to predict their price.
- Classification Problem: Given a patient with a tumor, we have to predict whether the tumor is malignant or benign.
