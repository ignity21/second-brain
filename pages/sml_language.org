  fun pow(x : int, y : int) =

      then 1
      else x * pow(x, y - 1)

      pow(x, 3)

  val y = cube(x);

* Functions
** Step1: Function Binding
- Syntax: ~fun x0 (x1 : t1, ..., xn : tn) = e~
- Evaluation: *A function is a value* (No evaluation for the body yet)
- Type-checking
  - The type checker will find out the return type of the function.
  - The body of the function is not evaluated.
** Step2: Function Calls
- Syntax: ~e0 (e1,...,en)~
- Type-checking
  - ~e0~ has some function  type ~(t1 *...* tn) -> t~
  - check arguments ~e1: t1 ...~
  - Then ~e0(e1,...,en)~ has type ~t0  ~
- Evaluation: Evaluate ~e0~ to a function ~fun x0 (x1: t1, ..., xn: tn) = e~
