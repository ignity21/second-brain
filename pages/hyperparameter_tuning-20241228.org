#+title: Hyperparameter Tuning
#+filetags: :ML:

* Hyperparameters
- Ridge/lasso regression: \(\alpha\)
- KNN: =n_neighbors=

* Tuning Steps
1. Try lots of hyperparameter values
2. Fit all of them separately
3. See how well they perform
4. Choose the best performing values


- It's essential to use [[id:5461b659-bc1a-4594-b7fb-8388345187d3][cross validation]] on the training set to avoid overfitting
- We withhold the test set for final evaluation
