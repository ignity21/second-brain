#+title: Exploratory Data Analysis
#+filetags: :Python:DataScience:

* Overview
- Detecting patterns and relationships
- Generating questions, or hypotheses
- Preparing data for machine learning

* Initial Exploration
- ~df.head()~
- ~df.info()~: show null-value and column type or ~df.dtypes~
- ~df.describe()~

* Numerical Data
- Previewing all numerical data: ~df.select_dtypes('number').head()~
- Use ~sns.boxplot()~ to overview distribution, ~y~ could be a categorical column
- Use ~astype(int)~ to convert data type
- ~min~, ~max~, ~describe~ to see range of data

* Categorical Data
- Previewing all categorical data: ~df.select_dtypes('object').head()~
- ~df['col1'].value_counts()~: count categorical values
  - ~sns.countplot(data=df, x='col1')~
- Number of Unique Values: ~df['col1'].nunique()~
- Exploring data using ~groupby~
- Use ~sns.barplot(..., x='categorical', ...)~ to see categorical summaries

*** Search Substrings & New Category
#+begin_src python
# find substring in a string
salaries["Designation"].str.contains("Machine Learning|AI")
salaries["Designation"].str.contains("^Data") # starts with Data

# multiple conditions
data_science = "Data Science|NLP"
data_analyst ="Analyst|Analytics"
manager = "Manager|Head|Director|Lead"
conditions = [
    salaries["Designation"].str.contains(data_science),
    salaries["Designation"].str.contains(data_analyst),
    salaries["Designation"].str.contains(manager)
]
job_categories = ["Data Science", "Data Analyst", "Managerial"]
salaries["Job_Category"] = np.select(conditions,
                                     job_categories,
                                     default="Other")
#+end_src

* Class Frequencies
- Sample should represents the population
- Class imbalance: one class occurs more frequently than others
  - bias results particularly if this class does not occur more frequently in the population
  - check frequency: ~df.value_count()~, ~normalize=True~ for percentage
- Another way to look at class frequency: Cross-tabulation
  - ~pd.crosstab(index=planes['Source'], columns=planes['Destination'])~ values will be the count
  - ~pd.crosstab(lanes['Source'], planes['Destination'], values=planes['Price'], aggfunc='median')~

* Creating Features
- *str* to *number*, useful functions:
  - ~df['col'].str.contains~, ~df['col'].str.replace~, ~df['col'].astype~
- *datetime* to *month/weekday/...*
  - ~df['col'].dt.month~, weekday, hour, ...
  - ~sns.heatmap(df.corr(), annot=True)~ to check relationships
- *number* to *category*
  - ~pd.cut~
  - ~sns.countplot()~ to explore the new category (maybe group by other category)

* Verifying Hypotheses
- Generating hypotheses by detecting relationships, differences, and patterns
- Then uses *Hypothesis Testing* to verify hypotheses
  - Generating a hypothesis or question
  - A decision on what statistical test to use
  - The process is known as *data snooping* or *p-hacking*

** Designing Experiments
- Involves steps such as:
  - Choosing a sample
  - Calculating how many data points we need
  - Deciding what statistical test to run
