* Bagged Decision Tree
- Given training set of size /m/
- For /b=1/ to /B/
  - Use sampling with replacement to create a new training set of size /m/
- All trees vote for the final prediction

* Random Forest
- Key idea: randomizing the feature choice to reduce the similarity of trees.

At each node, when choosing a feature to use to split, if /n/ features are available,
pick a random subset of $k<n$ features and allow the algorithm to only choose from that
subset of features.

* XGBoost(eXtreme Gradient Boosting)
** Idea
- Given training set of size /m/
- For /b=1/ to /B/
  - Use sampling with replacement to create a new training set of size /m/
  - Instead of picking from all examples with equal probability, make it more
    likely to pick examples that the previously trained trees *misclassify*.
  - Idea: Deliberate practice

- ~from xgboost import XGBRegressor~
