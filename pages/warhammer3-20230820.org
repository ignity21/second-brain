** 生命系
:PROPERTIES:
:ID:       e1167699-5abd-45d7-95ce-3c8068cde8bb
:END:
总结：普通大地之血+普通地灵觉醒
- 大地之血 :: 普通版性价比更高，触发被动多，基本不过载。使用对象：单体、高价值部队
- 石化之躯 :: 一般，物抗能叠到90%的话可用，对恶魔无用，与非恶魔英雄单挑可用，看情况过载
- 再生术 :: 性价比太低，临时救火用，救极重要单体单位可用，看情况过载
- 地灵觉醒 :: 漩涡烧血 别过载

** 火焰系
:PROPERTIES:
:ID:       baf9df31-00ea-40a1-b6d4-9281d9a8a54c
:END:
总结：前期可用，施法被动上弱火，配合可火攻单位（凤凰、巨龙、阿瓦隆）
- 流火披风 :: 耗蓝低，刷施法被动不错，看情况过载
- 鲁因火焰剑 :: 前期不错，非破甲魔攻火攻叠加施法被动，看情况过载
- 烈焰之颅 :: 前期不错 *移速慢* ，建议过载
- 穿刺焰矢 :: 指哪打哪 *反怪步* ，适用性高，一般不过载，扎堆范围大可过载
- 烈焰风暴 :: 误伤高，单体聚怪后用 别过载
