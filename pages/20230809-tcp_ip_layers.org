#+title: TCP/IP Layers
#+filetags: :Linux:Network:

* Data link layer
:PROPERTIES:
:ID:       5091bdbd-c716-49ad-82f0-1fef96c3646d
:END:
Provides *MAC routing*, *error detection* and *error correction*, and *flow control*.

* Network layer
:PROPERTIES:
:ID:       6a28873a-d9b7-4a8c-b2de-3a4da88d26ad
:END:
Routes data packets between different networks.

- [[id:3b7e1fae-01cb-4c83-adf1-ea97c3fb2946][MTU]]

* Transport layer
:PROPERTIES:
:ID:       df842644-7897-41ce-8d36-865a60c65bb2
:END:
Provides reliable end-to-end communication.

* Application layer
Provides services to applications that need to communicate over the network. HTTP, FTP, SMTP, etc.
