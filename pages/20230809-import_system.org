#+title: Import System
#+filetags: Python
* Finder
An object that tries to find the loader for a module that is being imported.
- ~PathFinder~
  - ~ZipImporter~
  - ~FileImporter~
- ~BuiltinImporter~
- ~FrozenImporter~

* Loader
An object that loads a module.
- ~SourceLessFileLoader~
- ~SourceFileLoader~
- ~ExtensionFileLoader~
- ...

* 模块元信息
- ~module.__dict__~
  - 例子： ~import math; math.__dict__~
  - ~__package__~: 所属package
  - ~__spec__~: ModuleSpec 模块元信息
  - ~__loader__~: 模块加载器

* Import Steps
1. ~import m~ （实际执行语句为 ~__import__(m)~ ）
2. ~_calc__package__~, then ~_resolve_name~ (relative import only)
4. ~_find_and_load~
   - ~_find_spec('m', path)~
   - ~_load_unlocked~: check ~__package__~ in the current module
5. 加载完成，存入 ~sys.modules~
