#+TITLE: Match the Device Size

- tags :: [[id:461cd1e9-bf22-4616-a61e-85fb0899f211][Meta Tag]], [[id:1fffe00d-b848-43ae-9711-8a6a136991b4][HTML Header]], [[id:06d80671-eef2-4472-a55a-7e437dfbc4e5][HTML Layout]]

Add viewport tag to the head element of the page
#+begin_src html
  <meta name="viewport" content="width=device-width,initial-scale=1">
#+end_src
- ~width=device-width~: to match the screen's width in device independent pixels(DIP).
- ~initial-scale=1~: 1 to 1 relationship between device independent pixels(DIP) and CSS pixels.
