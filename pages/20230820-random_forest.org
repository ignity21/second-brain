#+title: Random Forest
#+filetags: ML

- Key idea: randomizing the feature choice to reduce the similarity of trees.

At each node, when choosing a feature to use to split, if /n/ features are available,
pick a random subset of $k<n$ features and allow the algorithm to only choose from that
subset of features.
