#+TITLE: Logistic Regression

- tags :: [[id:e0e88d4d-69d2-4e20-be4c-5aa8b849e968][Classification Problem]], [[id:985a47ab-36b7-458b-b45b-a4abb934e8d9][Supervised Learning]], [[id:0ab07614-da61-4bd0-81be-08e294355ce5][Binary Classification]], [[id:89f66c7d-3d49-4308-91ae-1bb844fcbbec][Gradient Descent]]


* Hypothesis
$$h_\theta(\vec{x})=g(\theta^T\vec{x})=\frac{1}{1+e^{-\theta^T\vec{x}}}$$

$$h_\theta(\vec{x})=P(y=1|\vec{x},\theta)$$

** Logistic Function
or Sigmoid Function
$$g(z)=\frac{1}{1+e^{-z}}$$

- $g(z)\ge 0.5$ when $z\ge 0$ i.e. $\theta^T\vec{x}\ge0$

** Decision Boundary
The decision boundary is the line that separates the area where y = 0 and where y = 1.
It is determined by $\theta$.


* Cost Function
$$J(\vec{\theta})=\frac{1}{m}\sum_{i=1}^m Cost(h_\theta(\vec{x_i}), \vec{y_i})$$

$$Cost(h_\theta(x), y)=\begin{cases}
-\log(h_\theta(x)), & \text{if }y=1\\
-\log(1-h_\theta(x)), & \text{if }y=0
\end{cases}$$
[[../assets/ML/LogisticRegression_1.jpg]]

- Simplified Compact Version
$$Cost(h_\theta(x), y)=-y\log(h_\theta(x))-(1-y)\log(1-h_\theta(x))$$

* Gradient Descent Approach
$$\theta_j=\theta_j-\alpha\frac{\partial}{\partial\theta_j}J(\theta)$$

$$Gradient=\frac{\partial}{\partial\theta_j}J(\theta)=\frac{1}{m}\sum_{i=1}^m(h_\theta(x_i)-y_i)x_{ij}$$

* Vectorized Summary
- Hypothesis: $h=g(\mathbf{X}\theta)$
- Cost Function: $J(\theta)=-\frac{1}{m}\cdot(y^T\log(h)+(1-y)^T\log(1-h))$
** Gradient Descent
- Repeat until convergence: $\theta=\theta-\alpha\frac{1}{m}\mathbf{X}^T(g(\mathbf{X}\theta)-y)$

* Regularized Logistic Regression
** Cost Function
$$J(\theta)=-\frac{1}{m}\cdot(y^T\log(h)+(1-y)^T\log(1-h))+\frac{\lambda}{2m}\sum_{j=1}^n\theta_j^2$$
- $\theta_0$ should not be penalized

** Gradient Descent
- Repeat until convergence
$$\theta_0=\theta_0-\alpha\frac{1}{m}\sum_{i=1}^m(h_\theta(x_i)-y_i)x_{i0}$$

$$\theta_j=\theta_j-\alpha[\frac{1}{m}\sum_{i=1}^m(h_\theta(x_i)-y_i)x_{ij}+\frac{\lambda}{m}\theta_j]$$

- Vectorized(except $\theta_0$)
$$\theta=\theta-\alpha\frac{1}{m}[\mathbf{X}^T(g(\mathbf{X}\theta)-y)-\lambda\theta]$$
