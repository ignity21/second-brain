** Intuition
There are $n+1$ positive numbers in the array (numsnumsnums) (all in the range [1, n]).
Since the array only contains *positive integers*, we can track each number ~num~ that
has been seen before by flipping the sign of the number located at index ~|num|~, where
~||~ denotes absolute value.

If the ~nums[|num|]~ is already negative, indicating that ~num~ has been seen before and
hence is the duplicate number.
