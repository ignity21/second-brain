#+TITLE: Normal Equation
#+filetags: :ML:

- tags :: [[id:f05e4c45-31d8-47d0-bac8-183f1bc7447b][Cost Function]]

* Properties
- Only for [[id:46646008-096b-4086-beab-62c2dd5f5825][Linear Regression]]
- Solve for $\bm{w}, b$ without iterations
- No need to choose alpha
- No feature scaling
- Quite slow when number of features is large (> 10,000)

* Formula
$\bm\theta=(\bm{X}^T \bm{X})^{-1}\bm{X}^T\bm{y}$

$X^T X$ is a $n\times n$ matrix.

* If $X^T X$ is Non-invertible
- Use pseudo-inverse: ~np.linalg.pinv(a)~
- Remove redundant features: say $x_2 = C x_1$
- Too many features: m is notably less than n.
  - Delete some features
  - Use regularization
