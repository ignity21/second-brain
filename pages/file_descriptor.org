#+TITLE: File Descriptor

- tags :: [[id:60cfb15c-18c7-479a-b489-b14ce161f4bf][Process]], [[id:14987d03-a0b8-49f5-97ba-d51f37aafd5f][File System]]


- File Descriptor Flags :: Apply only to a single descriptor in a single process.
- File Status Flags :: Apply to all descriptors in any process that point to the given file table entry.


* ~dup~ and ~dup2~
Duplicate a file descriptor.
- ~dup(fd)~ is equivalent to ~fcntl(fd, F_DUPFD, 0)~
- ~dup2(fd, fd2)~ is equivalent to ~close(fd2); fcntl(fd, F_DUPFD, fd2)~. (*atomic* operation)
