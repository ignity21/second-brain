* Concept
Matrices make transformations on vectors, potentially changing their magnitude and direction.
- Square matrix: a $n\times n$ matrix
- Diagonal matrix

\[\begin{bmatrix}
4 & 0 & 0 \\
0 & 5 & 0 \\
0 & 0 & 6
\end{bmatrix}\]
#+begin_src python
  np.diag([4, 5, 6])
  M = ... # a matrix
  np.diag(M) # extract the diagonal values e.g. [4, 5, 6]
#+end_src

** Linear Transformation
- Any linear transformation $f$ that maps n-dimensional vectors to m-dimensional vectors can be represented as an $\bm{m\times n}$ matrix.

* Addition
- Commutative
- Associative

* Scale Multiplication
- Commutative
- Associative
- Distributive: $s(\bm{A}+\bm{B})=s\bm{A}+s\bm{B}$

* Matrix multiplication
- Not Commutative $\bm{A}\cdot \bm{B}\neq \bm{B}\cdot \bm{A}$
- Associative: $(\bm{A}\cdot\bm{B})\cdot \bm{C}=\bm{A}\cdot(\bm{B}\cdot\bm{C})$
** Geometric Application
*** Projection onto an axis
- The dot product of a unit vector and a matrix basically performs a projection on an axis
  - gives us the *coordinates* of the resulting points on that axis.
#+begin_src python
  unit_x = np.array[[1, 0]] #  matrix 1x2
  unit_x.dot(M) # result => horizontal coordinates
  # just projected  onto the horizontal axis

  angle30 = 30 * np.pi
  unit_30 = np.array([[np.cos(angle30), np.sin(angle30)]])
  unit_30.dot(M) # result => projection onto angle 30 Line
#+end_src

* Determinant
The determinant of a transformation represents the scale factor by which *areas* are transformed by the Matrix.
- To measure how much are areas scaled.
- [[https://youtu.be/Ip3X9LOh2dk?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab][Youtube]], [[https://www.bilibili.com/video/BV1ys411472E?p=7&vd_source=7540f00c721dbab673058cc445db02a0][bilibili]]
- $det(M)=5$: The transformation increases the area of a region by a factor of 5.
- $det(M)=0$: squishes areas into a *smaller dimension*.
  - Columns of the matrix must be *linearly dependent*.
- $det(M)=-2$: flips space over. [[https://www.bilibili.com/video/BV1ys411472E?p=7&vd_source=7540f00c721dbab673058cc445db02a0&t=228.8][Video]]

** Properties
- $det(AB)=det(A)\times det(B)$

* Inverse
- $A^{-1}\cdot A = I$
- Only square matrices can be inversed.
  - e.g. A transformation matrix performs projection onto an axis.
- *Singular matrix*: a square matrix that cannot be inversed.
#+begin_src python
  A_inv = LA.inv(A)
  # may raise "LinAlgError: Singular matrix"
#+end_src
- A matrix that is its own inverse is called an *involution*.
  - e.g. reflection matrices, or a rotation by 180°
- Test if a matrix can be inversed ~assert LA.inv(M) != 0~
  - If the determinant is equal to 0, then the matrix cannot be inversed. (it is a singular matrix)

* Composing Linear Transformation
#+begin_src python
  P_squeezed_then_sheared = F_shear.dot(F_squeeze.dot(P))
  P_squeezed_then_sheared = (F_shear.dot(F_squeeze)).dot(P) # associative

  # Perform dot product on transformation matrices first
  # lead to a very significant performance boost.
  F_squeeze_then_shear = F_shear.dot(F_squeeze)
  P_squeezed_then_sheared = F_squeeze_then_shear.dot(P)
#+end_src

** Inverse
- $(Q\cdot R)^{-1}=R^{-1}\cdot Q^{-1}$
#+begin_src python
  LA.inv(F_shear.dot(F_squeeze)) == LA.inv(F_squeeze).dot(LA.inv(F_shear)) # reversed order
#+end_src
