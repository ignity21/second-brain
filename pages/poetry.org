* Installation
- ~pipx install poetry~

** Oh-My-Zsh
#+begin_src bash
  mkdir $ZSH_CUSTOM/plugins/poetry
  poetry completions zsh > $ZSH_CUSTOM/plugins/poetry/_poetry
#+end_src

* Basic Usage
#+begin_src bash
  poetry new [project] # Creating new project
  # Modify pyproject.toml
  poetry install # Initialising a pre-existing project

  poetry add dependency

  poetry update # Updating dependencies

  poetry run python your_script.py
  poetry run pytest
#+end_src

* Specify Python Version
#+begin_src bash
  pyenv local x.x.x
  poetry env use x.x.x
#+end_src

* Configuration
- =$HOME/.config/pypoetry/config.toml=
#+begin_src conf-toml
  [virtualenvs]
  in-project = true
  prefer-active-python = true

  [repositories.pypi]
  url = "https://mirrors.aliyun.com/pypi/simple/"
#+end_src

* Issues
** Too Slow
- Global[Recommended]:
  - ~poetry config repositories.pypi "https://mirrors.aliyun.com/pypi/simple/"~
  - or in config file: =$HOME/.config/pypoetry/config.toml=

- In Project: =pyproject.toml=
#+begin_src conf
  [[tool.poetry.source]]
  name = "aliyun"
  default = true
  url = "https://mirrors.aliyun.com/pypi/simple/"
#+end_src
