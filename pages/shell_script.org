* 基础语法
** 引号
- 不带引号：无法在要显示的文本中使用分号；分号被用作命令分隔符
  - ~echo hello; world~: "command not found: world"
- 双引号：无法使用 ~!~ 号，需要转义 ~\!~
  - ~echo "hello world\!"~ -> =hello world!=
- 单引号：Bash 不会对单引号中的变量 ~$var~ 求值
  - ~echo '$var'~ -> =$var=

** 彩色输出
- 重置=0，黑=30，红=31，绿=32，黄=33，蓝=34，……
- 设置颜色 ~\e[1;31]~ 还原 ~\e[0m~
  - ~echo "\e[1;31m This is red.\e[0m"~

** 变量
- 每一个变量的值都是 *字符串*
*** 赋值
- ~var=value~
- ~var="Hello world\!"~
- ~var = value=~: 非赋值，是相等判断

*** 使用变量
- ~echo $var~ or ~echo ${var}~
- 双引号中使用变量 ~echo "show value ${var} $var"~

** 特殊变量
- ~$0~: 当前脚本名
- ~$?~: 前一次运行命令的退出码，0 表示成功


* 数值运算
** 整数运算
#+begin_src bash
  a=4;
  b=5;

  let result=a+b
  result=$[ a + b ]
  result=$[ $a + $b ]
  result=$(( a + b ))
  result=`expr $a + $b`
  result=$(expr $a + $b)
#+end_src

** 浮点数运算
#+begin_src bash
  d=5.4
  echo "scale=5;$d/9" | bc
  echo "sqrt(10)" | bc
  echo "10^10" | bc
#+end_src

** 进制转换
#+begin_src bash
  echo "obase=2;32" | bc # 十进制转二进制
  echo "obase=10;ibase=2;1111" | bc # 二进制转十进制
#+end_src

* 环境变量
环境变量是未在当前进程中定义，而是从父进程中继承而来的变量。

** 查看
- 查看当前终端环境变量： ~env~
- 查看进程环境变量： =/proc/$PID/environ=, 环境变量之间以 '\0' 分割
  - ~cat /proc/$PID/environ | tr '\0' '\n'~: 替换 '\0' 输出

** 设置环境变量
#+begin_src bash
  HTTP_PROXY=http://127.0.0.1:8080
  export HTTP_PROXY
  # or
  export HTTP_PROXY=http://127.0.0.1:8080
#+end_src

** 系统环境变量文件
- ~/etc/environment~: system-wide, applied to all users
- ~/etc/profile~: run for all users on the system when they log in
- ~~/.config/environment.d/~: store environment variable configuration files on some Linux distributions
- ~~/.bashrc~: run every time you start a new bash shell

* 重定向
标准文件描述符： ~stdin(0)~, ~stdout(1)~, and ~stderr(2)~
- 也可用 =/dev/stdin=, =/dev/stdout=, and =/dev/stderr=
- stdout, stderr 重定向到同一文件描述符 ~cmd &> file~

** ~tee~
主要用法：重定向文件同时，管道输出到下个命令
- ~tee~ 将 =stdin= 数据的一份副本写入 *文件* ，另一个副本传给下一个命令
- Example: ~command | tee out.txt | cat~
- ~tee -a out.txt~: 追加到文件

** 标准输入用法
  - ~echo 42 | cat~: 常规用法
  - ~echo 42 | cat -~: '-' 代表 stdin
  - ~echo 42 | cat /dev/stdin~
  - ~cmd < file~: 从文件中读取到 stdin

** 重定向文本块到文件
#+begin_src bash
  cat <<EOF>log.txt
  test file header
  EOF
#+end_src
- ~cat <<EOF>log.txt~ 到 ~EOF~ 之间的所有内容写入到文件

** 自定义文件描述符
使用 ~exec~ 命令
#+begin_src bash
  exec 3<input.txt # 使用文件描述符3打开并读取文件
  cat <&3 # 后续命令可使用文件描述符3

  exec 4>output.txt # 用于写入文件
  # 追加模式，用 4>>output.txt
  echo "hello world\!" >&4
#+end_src
* 数组
#+begin_src bash
  array=(1 2 3 4 5 6)
  # or
  array_test[0] = "a"
  array_test[1] = "b"

  # print
  echo ${array[0]}
  echo ${array_test[*]} # or ${array_test[@]}
  echo ${#array_test[*]} # 元素个数
#+end_src
** 关联数组
#+begin_src bash
  declare -A ass_array # 声明关联数组

  # add values
  ass_array=([index1]=val1 [index2]=val2)
  # or
  ass_array[index1]=val1
  ass_array[index2]=val2

  # print
  echo ${ass_array[index1]}
  echo ${!ass_array[*]} # 列出索引列表 or ${!ass_array[@]}
#+end_src

* Tricks
- 获取字符串长度： ~${#var}~
- 识别当前 Shell ： ~echo $SHELL~ or ~echo $0~
- 修改 Bash 提示字符串：利用环境变量 =PS1= 定制提示字符串
