* Hypothesis
A hypothesis function could be
- Quadratic: $\theta_0+\theta_1 x_n + \theta_2 x_n^2$
- Cubic: $\theta_0+\theta_1 x_n + \theta_2 x_n^2 + \theta_3 x_n^3$
- Square Root: $\theta_0+\theta_1 x_n + \theta_2 \sqrt{x_n}$

** Tricks
- new features
  - $x_1=x_n$
  - $x_2=x_n^2$
  - $x_3=x_n^3$
