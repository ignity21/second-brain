* Hypothesis
A hypothesis function could be
- Quadratic: $w_1 x + w_2 x^2 + b$
- Cubic: $w_1 x + w_2 x^2 + w_3 x^3 + b$
- Square Root: $w_1 x + w_2 \sqrt x + b$
