#+title: =/proc/=
#+filetags: Linux

=/proc/= 目录是一个特殊的虚拟文件系统，用于在 Linux 系统中提供对内核和系统信息的访问。它不包含实际的文件，而是提供文件方式来查看和操作正在运行的内核和系统状态的信息。
- The kernel creates them *"on the fly"* as processes access them.

* 帮助
~man 5 proc~

- =/proc/meminfo=

- =/proc/net/=: 网络信息
  - files: =sockstat=, =sockstat6=, =tcp=, =tcp6=, =udp=, =udp6=

* Useful Files in =/proc/[PID]/=
  - =exe=: symbolic to file being executed
  - =cmdline=: command-line arguments
  - =stat=: for program
  - =status=: provides a range of information about the process.
  - =cwd/=: symbolic to current working directory
  - =environ=: /NAME=value/ pairs
  - =fd=: symbolic links to files opened by the process
  - =maps=: memory mappings
  - =mem=: process virtual memory (must ~lseek()~ to valid offset before I/O)
  - =mounts=: mount points for the process
