#+TITLE: Gradient Descent

- tags :: [[id:46646008-096b-4086-beab-62c2dd5f5825][Linear Regression]], [[id:f05e4c45-31d8-47d0-bac8-183f1bc7447b][Cost Function]], [[id:c4114af3-a40b-422b-af14-077d4a0cfed6][Logistic Regression]]


* Outline
1. Use *feature scaling* to accelerate the progress of the gradient descent.
   - Get every feature into approximately a $-1\le x_n \le 1$ range.
   - Mean normalization $x_n=\frac{x_n-\mu_n}{s_n}$ where $s_n$ could be the std or range of $x_n$.
   - Divided by maximum
2. Start with some $\vec{\theta}$ may be $\vec{0}$
3. Keep changing $\vec{\theta}$ to reduce cost function $J(\vec{\theta})$
4. Repeat until convergence
$$\theta_n = \theta_n - \alpha\frac{\partial}{\partial\theta_n}J(\vec{\theta})$$

* Details
- multiple local minimum
- $\alpha$: Learning rate. How to choose a $\alpha$
  - if $\alpha$ is too small, gradient descent can be slow to converge.
  - if $\alpha$ is too large, gradient descent can overshoot the minimum.
  - Can plot *No. of iterations* -> $J(\vec{\theta})$ to help choose a $\alpha$
  - try ..., 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1, ...
- "Batch" Gradient Descent: Each step of gradient descent uses all the training examples.

* Regularization
- To penalize for large values of $\theta_j$

$$J(\vec{\theta})=\frac{1}{2n}\sum_{i=1}^n(h_\theta(\vec{x}^{(i)})-y^{(i)})^2+\frac{\lambda}{2}\sum_{j=1}^d\vec{\theta_j^2}$$

- $\lambda$ is the regularization paramenter ($\lambda\ge 0$)
- No regularization on $\theta_0$

** Gradient Update
$$\theta_0=\theta_0-\frac{\alpha}{n}\sum_{i=1}^n(h_\theta(x^{(i)})-y^{(i)})$$

$$\theta_j=\theta_j-\frac{\alpha}{n}\sum_{i=1}^n(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}-\lambda\theta_j$$

- rewrite as:
$$\theta_j=\theta_j(1-\alpha\lambda)-\frac{\alpha}{n}\sum_{i=1}^n(h_\theta(x^{(i)})-y^{(i)})x_j^{(i)}$$
