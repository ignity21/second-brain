- with ~fig~ and ~ax~
#+begin_src python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(2, 1) # figure, axes with 2 rows, 1 column

ax[0].plot(aapl["datetime"], aapl["close"], label="AAPL")
# options:
# marker="o", linestyle="--", color="red", linewidth=2

# Always label your axes
ax[0].set_xlabel("Date")
ax[0].set_ylabel("Price")

ax[1].plot(nvda["datetime"], nvda["close"], label="NVDA")
ax[1].set_xlabel("Date")
ax[1].set_ylabel("Price")

ax[0].legend() # legend is used to show the labels
ax[1].legend()

plt.show()
#+end_src

* Charts
** Bar
#+begin_src python
fig, ax = plt.subplots()
ax.bar(medals["country"], medals["gold"], color="gold", label="Gold")
ax.bar(medals["country"], medals["silver"], color="silver", label="Silver",
       bottom=medals["gold"]) # bottom=medals["gold"] is used to stack the bars

ax.bar(medals["country"], medals["bronze"], label="Bronze", bottom=medals["gold"] + medals["silver"])

ax.set_xticklabels(medals["country"], rotation=90)
ax.set_ylabel("Number of medals")

ax.legend()
plt.show()
#+end_src

* Customization
- ~plt.style.use('seaborn-colorblind')~ See [[https://matplotlib.org/stable/gallery/style_sheets/style_sheets_reference.html][Styles]]
- ~fig.savefig("pic.png", dpi=300)~ to save your visualization
  - ~fig.set_size_inches([5, 3])~

** Guidelines for Choosing Style
- Avoid using dark backgrounds
- Colorblind-friendly options: =seaborn-colorblind=, =tableau-colorblind10=
- Using less ink for printers: Avoid colored backgrounds
- Black-and-white: =grayscale=
