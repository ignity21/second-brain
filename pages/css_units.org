#+TITLE: CSS Units

- tags :: [[id:2233d2b3-9810-4f8f-b92c-dcb4eec93561][Frontend]]

* Absolute Units
- px, in, mm, cm
#+begin_src css
  .sidebar {
      width: 400px;
  }
#+end_src

* Relative Units
- %, em, vw, vh

** em
1.5em is equivalent to 1.5 times the font size of the current element.

* Pixel
- Physical Hardware Pixels
- Device Independent Pixels(DIP): relates pixels to a real distance.
- Device Pixel Ratio(DPR): Physical / DIP

** Example
A browser has a *viewport* width of 1280 dips. The device pixel ratio is 2.
The 1280 dips get scaled up to the 2560 hardware pixels.


* Viewport
#+begin_src html
  <meta name="viewport" content="width=device-width, initial-scale=1">
#+end_src
