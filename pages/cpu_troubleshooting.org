* CPU性能问题排查
1. CPU使用率
  - 用户 CPU 使用率：应用程序比较忙
  - 系统 CPU 使用率：内核比较忙
  - 等待 I/O 使用率: 系统与硬件设备的I/O交互时间较长
  - 软中断和硬中断
2. 平均负载
3. 进程上下文切换
  - 无法获取资源而导致的自愿上下文切换
  - 被系统强制调度导致的非自愿上下文切换
4. CPU缓存命中率
