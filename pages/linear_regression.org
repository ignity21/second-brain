#+TITLE: Linear Regression
#+filetags: :ML:

- tags :: [[id:4d9aa428-be23-4297-b24f-6f5d05f565f4][Regression Problem]]

* Concept
** Parameters
- Weights: $\bm{w}$: $w_1, w_2, \cdots, w_n$
- Bias: $b$

** Model
\[f_{\bm{w}, b}(\bm{x})= w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b=\bm{w}\cdot\bm{x}+b=\bm{w}^T\bm{x} + b\]
- Vector dot product: ~f = np.dot(w, x) + b~
- Matrix product: ~f = w.T @ x + b~
  - ~w.T~ is $1\times n$ matrix
  - ~x~ is $n\times 1$ matrix

** [[id:f05e4c45-31d8-47d0-bac8-183f1bc7447b][Cost Function]]
- Loss Function: [[id:e58f6702-79c4-4e2c-9799-187b452ef6d0][MSE]]
\[J(\bm{w}, b)=\frac{1}{m}\sum_{i=1}^m(\bm{w}^T\bm{x^{(i)}}+b-y^{(i)})^2\]

** Goal: Minimize $J(\bm{w}, b)$
*** [[id:89f66c7d-3d49-4308-91ae-1bb844fcbbec][Gradient Descent]]
\[w_j=w_j-\alpha\frac{\partial}{\partial w_j}J(\bm{w}, b)\]

\[b=b-\alpha\frac{\partial}{\partial b}J(\bm{w}, b)\]

**** Details
\[\frac{\partial}{\partial{w_j}}J(\bm{w}, b)=\frac{2}{m}\sum_{i=1}^{m} (f_{\bm{w}, b}(\bm{x^{(i)}}) -y^{(i)})x_{j}^{(i)}\]

\[\frac{\partial}{\partial{b}}J(\bm{w}, b)=\frac{2}{m}\sum_{i=1}^{m} (f_{\bm{w}, b}(\bm{x^{(i)}}) -y^{(i)})\]

*** [[id:04c99717-5839-4808-ab6b-116a0839b9f6][Normal Equation]]

* Vectorized
- Hypothesis vector $\bm{\hat{y}} = \bm{Xw} + \bm{b}$
** Cost Function
- $J = \frac{1}{m}(\bm{Xw}+\bm{b}-y)^T(\bm{Xw}+\bm{b}-y)$
#+begin_src python
  import numpy as np
  J = (1/m) * np.matmul(error.T, error)
#+end_src
** Gradient Descent
- Gradient (partial derivatives)

\[\frac{\partial}{\partial{w_j}}J(\bm{w}, b)=\frac{2}{m}\sum_{i=1}^m(\bm{w}^T\bm{x^{(i)}}+b-y^{(i)})x_j^{(i)}\]

\[\frac{\partial}{\partial{b}}J(\bm{w}, b)=\frac{2}{m}\sum_{i=1}^m(\bm{w}^T\bm{x^{(i)}}+b-y^{(i)})\]


- Gradient Vector for *w*

\[\frac{2}{m} \bm{X}^T(\bm{Xw}+\bm{b}-\bm{y})\]

- Gradient for b

\[\frac{2}{m} \vec{1}(\bm{Xw}+\bm{b}-\bm{y})\]


- repeat until convergence
\[\bm{w}=\bm{w}-\alpha\frac{2}{m}\bm{X}^T(\bm{X}\bm{w} +\bm{b}-\bm{y})\]

\[b = b - \alpha\frac{2}{m}\vec{1}(\bm{X}\bm{w} +\bm{b}-\bm{y})\]

** Normal Equation($\theta$ version)
\[\hat{\theta}=(\bm{X}^T\bm{X})^{-1}\bm{X}^T\bm{y}\]

  # X.T @ X calls np.matmul(X.T, X)
