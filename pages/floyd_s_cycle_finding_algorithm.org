#+TITLE: Floyd’s Cycle Finding Algorithm
#+filetags: :Algorithm:

- tags :: [[id:43e3d72c-1b4a-4ce0-a844-25348fe594ce][Algorithm]]

This algorithm is used to find a loop in a linked list. It uses two pointers one moving
twice as fast as the other one. The faster one is called the faster pointer and the
other one is called the slow pointer.

- The Fast pointer may reach the end (NULL) this shows that there is no loop in the linked list.
- The Fast pointer again catches the slow pointer at some time therefore a loop exists in the linked list.
- Slow pointer name: ~tortoise~
- Fast pointer name: ~hare~
