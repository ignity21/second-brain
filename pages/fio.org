#+TITLE: ~fio~

- tags :: [[id:10238dbb-e053-409b-9ee2-32df8af4d748][Testing]], [[id:4480ae6d-c8ce-4f01-81ac-b04ff9a90fff][I/O Troubleshooting]]


~fio~ is a tool that will spawn a number of threads or processes doing a particular type of I/O action

#+begin_src bash
  # 随机读
  fio -name=randread -direct=1 -iodepth=64 -rw=randread -ioengine=libaio -bs=4k -size=1G -numjobs=1 -runtime=1000 -group_reporting -filename=/dev/sdb

  # 随机写
  fio -name=randwrite -direct=1 -iodepth=64 -rw=randwrite -ioengine=libaio -bs=4k -size=1G -numjobs=1 -runtime=1000 -group_reporting -filename=/dev/sdb

  # 顺序读
  fio -name=read -direct=1 -iodepth=64 -rw=read -ioengine=libaio -bs=4k -size=1G -numjobs=1 -runtime=1000 -group_reporting -filename=/dev/sdb

  # 顺序写
  fio -name=write -direct=1 -iodepth=64 -rw=write -ioengine=libaio -bs=4k -size=1G -numjobs=1 -runtime=1000 -group_reporting -filename=/dev/sdb
#+end_src
- direct，表示是否跳过系统缓存, 1跳过。
- iodepth，表示使用异步 I/O（asynchronous I/O，简称 AIO）时，同时发出的 I/O 请求上限。
- rw，表示 I/O 模式。
- ioengine，表示 I/O 引擎，它支持同步（sync）、异步（libaio）、内存映射（mmap）、网络（net）等各种 I/O 引擎。
- bs，表示 I/O 的大小。
- filename，表示文件路径，当然，它可以是磁盘路径（测试磁盘性能），也可以是文件路径（测试文件系统性能）。

* 报告指标
- slat ，是指从 I/O 提交到实际执行 I/O 的时长（Submission latency）
- clat ，是指从 I/O 提交到 I/O 完成的时长（Completion latency）
- lat ，指的是从 fio 创建 I/O 到 I/O 完成的总时长。
