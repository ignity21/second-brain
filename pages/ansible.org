* Installation
** ~pip~
#+begin_src bash
  pip install --user ansible
  # or using pipx
  pipx install --include-deps ansible
#+end_src

** ubuntu
#+begin_src bash
  sudo apt-add-repository ppa:ansible/ansible
  sudo apt update
  sudo apt install ansible
#+end_src

* Usage
** Configuration File
#+begin_src bash
  # Generating a sample ansible.cfg file
  ansible-config init --disabled > ansible.cfg
  sudo chmod 644 ansible.cfg
#+end_src

** Inventory
#+begin_src yaml
  group1:
	hosts: # keyword
	  host_local: xxx # alias
		ansible_host: localhost
		ansible_connection: local
		proxy: test.sock5 # host variable
	  host_remote:
		ansible_host: foo.remote # domain name or IP
		ansible_connection: ssh
		ansible_user: testuser # default current local user
	vars: # group vars
	  ntp_server: ntp.example.com

  group_all:
	children:
	  group1:
#+end_src
#+begin_src bash
  # verifys the inventory
  ansible-inventory -i inventory.yaml --list
  ansible -i inventory.yaml all -m ping
#+end_src

** SSH Connection
- The use of ssh-agent is highly recommended.
#+begin_src bash
  ssh-agent zsh
  ssh-add ~/.ssh/private_key
#+end_src
*** Running with ~sudo~
1. Sets ~become: ture~ and ~become_password: xxx~ in the playbook.
2. Adds =username ALL=(ALL) NOPASSWD: ALL= to =/etc/sudoers= file.

** Ad hoc Commands
#+begin_src bash
  ansible group1 -a "pwd"
  ansible group1 -a "/sbin/reboot" -f 5 -u user2

  # files
  ansible group1 -m ansible.builtin.copy -a "src=/etc/hosts dest=/tmp/hosts"
  ansible webservers -m ansible.builtin.file -a "dest=/srv/foo/b.txt mode=600 owner=mdehaan group=mdehaan"

  # package manager
  # ansible.builtin.yum, ansible.builtin.apt
  # sudo command options: --become --ask-become-pass
  ansible sandboxes -m ansible.builtin.apt -a "name=build-essential" --become --ask-become-pass

  # services
  ansible webservers -m ansible.builtin.service -a "name=httpd state=started"
#+end_src
