* ~std::shared_future~
Waiting for the same event from more than one thread.
** Usage
The preferred way to use it would be to pass a *copy* of the ~shared_future~ object to each thread.

** Use Case
One potential use is for implementing [[id:ceda8de0-12cd-464e-8864-407748927109][Parallel Execution]].

** Transferred from ~std::future~
#+begin_src c++
  std::future<double> f = std::async(square_root, 4);
  std::shared_future<double> sf = std::move(f);
  // leave f in an empty state, can not be used anymore.
#+end_src
