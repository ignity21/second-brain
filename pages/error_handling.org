#+TITLE: Error Handling

- tags :: [[id:ed1a8a51-ec7f-42fb-9ee5-606f855ff529][Linux Error Handling]], [[id:78a71436-87e6-4ec2-bf29-a3c08c57de36][Exception Handling]]


* 两种方式
- 错误码返回值
- 异常处理

** 如何选择
- 对于我们并不期望发生的事，使用异常捕捉；否则使用返回码
- 条件限制下，只能用一种方式；比如  RPC 只能用返回码

* 资源清理问题
- [[id:642577bf-1c0e-4177-b6a7-0c9678a81d51][C++ RAII]]
- ~finally~ 块
- Go 的 defer 模式
- C 的 goto fail 模式

* 错误分类
- 资源错误，比如网络故障、内存耗尽、栈溢出等
  - 关键资源错误：报错停止运行
  - 环境问题：重试
- 程序错误，空指针、非法参数等
  - 日志及监控
- 用户输入错误
  - 客户端报错
  - 需要统计错误率，帮助改善软件及侦测恶意用户请求
