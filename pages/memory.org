- 虚拟内存 :: 包括了进程代码段、数据段、共享内存、已经申请的堆内存和已经换出的内存等。
- 常驻内存 :: 进程实际使用的物理内存，不包括 Swap 和共享内存。
- 共享内存 :: 包括与其他进程共同使用的真实的共享内存，还包括了加载的动态链接库以及程序的代码段等。
- Swap 内存 :: 通过 Swap 换出到磁盘的内存。
