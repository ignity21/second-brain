** Expressing Intent
*** relaxed
#+begin_src c++
std::atomic<size_t> count;
count.fetch_add(1, std::memory_order_relaxed);
#+end_src
count is not used to index any memory or as a reference count.(no other memory access depends on it) - it's just a counter.

*** release
#+begin_src c++
std::atomic<size_t> count;
T data[max_count];
initialize(data[count.load(std::memory_order_relaxed)]); // nobody can see this yet
count.fetch_add(1, std::memory_order_release); // make it visible, now they can see it
// in reader thread, it should load with std::memory_order_acquire
#+end_src
count indexes some memory that was prepared by this thread and now is release to other threads.

* When to Use?
- High-performance concurrent lock-free data structures
- When drawback of locks are important (deadlocks, priority conflicts, latency problems)
- Data structures that are difficult or expensive to implement with lock
- When concurrent synchronization can be achieved by the cheapest atomic operations (RCU)

* Simple Lock-free Examples
** Atomic Queue
#+begin_src c++
int q[N];
std::atomic<size_t> front{0};
void push(int x) {
    size_t pos = front.fetch_add(1, std::memory_order_release);
    q[pos] = x;
}

int pop() {
    size_t pos = front.fetch_sub(1, std::memory_order_acquire) - 1;
    return q[pos];
}
#+end_src

** Atomic List
#+begin_src c++
struct node {int value; node *next; };
std::atomic<node*> head;
void push_front(int x) {
    node *new_node = new node;
    new_node->value = x;
    node *old_head = head;
    do { new_node->next = old_head; }
    while (!head.compare_exchange_strong(old_head, new_node));
    // if head == old_head, head = new_node
    // else old_head = head, then continue
}
#+end_src
