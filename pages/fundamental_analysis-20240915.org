#+title: Fundamental Analysis
#+filetags: :FA:Trading:

* Definition
Evaluating a stock's price based on it's revenues, earnings, future growth, return on equity,
profit margins, etc.

Evaluation is done by examining a company's income statements, it's earning releases and balance sheet.
