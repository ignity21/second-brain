- ~pipx install pipenv~

* Basic Usage
#+begin_src bash
  cd project-dir
  pipenv install requests
  pipenv install --dev pyright pyls
  pipenv run python main.py # run a command inside the virtualenv
  pipenv shell # activate this project's virtualenv
