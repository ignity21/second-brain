* 识别问题可以用动态规划解决
1. 最优解问题。（最大最小值）
2. 整体问题的最优解包含子问题的最优解

* 经验
1. 每一步有多个选项
2. 找出子状态；通常一个选项对应一个子状态
3. 分析前一步到后一步的状态转移
4. 重复子状态注意缓存

* 解题思路
*动态规划简单归纳就是 递推+记忆*
1. 定义子问题
2. 递推方程
3. 子问题的解合并
4. 递归和记忆（DP状态表，存储中间状态）

- *递归思想是自上而下，改写成循环需要自下而上*

** 状态转移表法
1. 先用回溯算法解决
2. 定义状态
3. 画出递归树
4. 找出重复子问题
5. 画状态转移表，根据递推关系分阶段填充状态表中的每个状态。
   - 状态转移表法适用于二维数组，达到多维时，就不适合用状态转移表法解决了
   - 思考时画出二维数组，代码实现可根据情况简化成一维数组
   - 行、列、值分别对应阶段、限制、最优值
   - 有时可用哨兵值简化代码实现；如零钱凑法问题

** 状态转移方程法
1. 找出解决后续问题的最优子结构
2. 根据最优子结构，写出 *状态转移方程* ，即递推公式
3. 实现可用两种方式，一种是递归+缓存，另一种是迭代递推

* 解题步骤
1. 确定 dp 数组（dp table）以及下标的含义
2. 确定递推公式
3. dp 数组如何初始化 (举例推导 dp 数组)
4. 确定遍历顺序

** 例：斐波那契数
1. dp[i] 的定义：第 i 个数的斐波那契数值是 dp[i]
2. 递推公式 ~dp[i] = dp[i-2] + dp[i-1]~
3. ~dp[0]=0~, ~dp[1]=1~
4. dp[2] 由 dp[1] 和 dp[0] 推来，顺序从前往后
5. =0 1 1 2 3=

** 例：背包问题（最大价值）
1. dp[i][j] 的定义：选择下标为 i 的物品加入或不加入重量为 j 的背包，价值最大为 dp[i][j]
2. 递推公式：
   - 选择不加入 ~dp[i][j] = dp[i-1][j]~
   - 选择加入 ~dp[i][j] = max(dp[i-1][j-weight[i]]+value[i], dp[i-1][j])~
3. 没有任何物品时： ~dp[0][j] = {0...}~
4. 顺序，dp 表 上到下，左到右

* 与其他算法比较
- 回溯算法：动态规划比回溯算法高效，但并不是所有能用回溯解决的问题都能用动态规划解决
- 分治算法：分治不能有重复子问题，动态规划正好相反
- 贪心算法：问题需要有贪心选择性，即通过局部最优的选择，能产生 *全局* 最优解
