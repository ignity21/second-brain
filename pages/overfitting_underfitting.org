* Generalization
A model is able to make accurate predictions on unseen data.
- It is able to generalize from the training set to the test set.

* Overfitting/Underfitting
- Choosing too simple a model is called underfitting
- Overfitting occurs when you fit a model too closely to the particularities of the training set.
- If dataset is large enough, it becomes harder for a model to overfit, or memorize the data.
- Too many features will cause overfitting


* Reducing Overfitting
1. Reduce number of features
   - Manually select which features to keep.
   - [[id:929621f8-f5c6-4bb1-8ce7-c5c79fcdafa6][Model Selection]] Algorithm
2. Regularization: Keep all the features, but reduce magnitude/values of parameters $\theta_j$
