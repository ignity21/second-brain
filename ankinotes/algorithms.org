def reverse(head):

    return prev

** Floyd 判圈找环入口
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
快慢指针在环内相遇后，为什么让一个指针回到链表头、两个指针都每次走 1 步，它们会在环入口相遇？

*** Back
设头到入口距离 $a$ ，入口到相遇点 $b$ ，环长 $L$ 。慢指针走了 $a+b$ ，快指针走了 $2(a+b)=a+b+kL$ ，所以 $a=kL-b$ 。
从相遇点走 $kL-b$ 步正好回到入口，而从头走 $a$ 步也到入口，两者同时到达。

Source: Linked List Techniques

** 单调栈：下一个更大元素
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
写出 ~next_greater(nums)~ ：返回每个位置右边第一个更大元素的值，没有则为 -1，要求 O(n)。

*** Back
#+begin_src python
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []                     # 存下标，对应值递减
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        stack.append(i)
    return res
#+end_src
每个元素只进出栈一次。存下标而不是值，才能算距离（LT739）。

** 数据流的中位数
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
数据流中随时求中位数，用什么结构？插入时如何保持平衡？

*** Back
两个堆：大顶堆 ~lo~ 存较小的一半（ ~heapq~ 存相反数），小顶堆 ~hi~ 存较大的一半。
插入：先放进 ~lo~ ，再把 ~lo~ 的最大值移到 ~hi~ ；若 ~hi~ 比 ~lo~ 多，再移回一个。保持 ~len(lo) >= len(hi)~ ，中位数是 ~lo~ 堆顶或两个堆顶的平均。

** 中序遍历的迭代写法
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
用一个栈写出二叉树中序遍历 ~inorder(root)~ 。

*** Back
#+begin_src python
def inorder(root):
    res, stack, node = [], [], root
    while node or stack:
        if node:
            stack.append(node)
            node = node.left       # 一路向左压栈
        else:
            node = stack.pop()
            res.append(node.val)   # 左边到底：处理栈顶
            node = node.right      # 转向右子树
    return res
#+end_src

** Morris 遍历的思路
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
Morris 中序遍历如何做到 O(1) 额外空间？它用什么代替了栈？

*** Back
栈的作用是「处理完左子树后跳回当前节点」。Morris 把左子树最右节点（中序前驱）的空 ~right~ 指针临时指向当前节点：第一次到达当前节点时建这条线索并进入左子树；沿线索第二次回到它时拆掉线索、处理它、转向右子树。
代价：遍历期间修改了树，中途退出会留下线索。

Source: Binary Tree Traversal

:ANKI_NOTE_TYPE: CC Basic

计数排序算出前缀和 ~cnt~ 后，把元素放进结果数组时为什么要从原数组的 *末尾* 往前遍历？

** A* 的启发函数条件
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
A* 的 $f = g + h$ 中，启发函数 $h$ 满足什么条件才保证找到最短路径？满足什么条件节点第一次出堆就可以关闭？

*** Back
- 可采纳（admissible）：$h$ 从不高估到终点的真实距离 → 结果最短。
- 一致（consistent）：每条边满足 $h(n) \le c(n,m) + h(m)$ → 节点第一次出堆时的 $g$ 已是最优，可直接关闭。
- $h \equiv 0$ 时就是 Dijkstra。四方向单位代价网格上，曼哈顿距离两者都满足。

Source: A* Search

** 动态规划、分治与贪心

:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
动态规划和分治、贪心的本质区别各是什么？

*** Back

** 有序数组去重保留 k 个
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
写出 ~remove_duplicates(nums, k)~ ：有序数组原地去重，每个值最多保留 k 个，返回新长度（LT26 / LT80）。

*** Back
#+begin_src python
def remove_duplicates(nums, k=1):
    slow = 0                      # nums[:slow] 是结果
    for x in nums:
        if slow < k or nums[slow - k] != x:
            nums[slow] = x
            slow += 1
    return slow
#+end_src
和结果中倒数第 k 个比较：相同说明这个值已经有 k 个了。

** KMP 前缀函数
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
写出 KMP 的前缀函数 ~prefix_function(p)~ ，并给出 ~"aabaaf"~ 的结果。

*** Back
#+begin_src python
def prefix_function(p):
    pi, j = [0] * len(p), 0
    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]          # 退到更短的相等前后缀
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi
#+end_src
~"aabaaf"~ → ~[0, 1, 0, 1, 2, 0]~ 。匹配文本时失配同样执行 ~j = pi[j - 1]~ ，文本指针不回退。

Source: KMP String Matching

** 重复子串的判断
:PROPERTIES:
:ANKI_NOTE_TYPE: CC Basic
:END:

*** Front
LT459：如何用前缀函数判断字符串 ~s~ 是否由某个子串重复多次构成？

*** Back
设 ~n = len(s)~ 、 ~L = pi[-1]~ （最长相等真前后缀长度）。当 ~L > 0~ 且 ~n % (n - L) == 0~ 时成立，重复单元长度为 ~n - L~ 。
例： ~"abab"~ 的 ~L = 2~ ，4 % 2 == 0，成立； ~"aba"~ 的 ~L = 1~ ，3 % 2 ≠ 0，不成立。

Source: KMP String Matching
