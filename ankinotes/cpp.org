*** Back
- ~&ptr~ : address of pointer itself
- ~ptr~ : address of array
- ~array~ : address of array
- ~*ptr~ : value of first element
- ~ptr[0]~ : value of first element
- ~*(++ptr)~ : increment pointer second and value of second
- ~*(ptr++)~ : increment pointer to third and value of second
