# 学习目标

各领域的学习角度、目标档位和用途，供处理收件箱和在库里学习时决定内容深度。档位（不需要 / 知道 / 能判断 / 能写）的定义见 [cc-note-writing](skills/cc-note-writing/SKILL.md)「掌握目标与载体」。用户可随时修改；AI 只记录用户说过的内容。

## 计算机网络

记录于 2026-10-16。

- **角度**：程序员视角，不是运维视角。
- **用途**：
  - 应付面向程序员的网络面试题；遇到过的题多为协议问题，集中在 IP 层和 TCP 层。
  - 配置家庭网络：路由器常见配置项，尤其是 OpenWRT 能配的常用项。

| 子领域 | 档位 | 说明 |
|---|---|---|
| TCP 机制：三次握手、流量控制、拥塞控制等 | 能判断 | 面试问得最多，要能讲清机制和原因 |
| IP 层协议 | 能判断 | 面试常见 |
| VLAN 基本概念 | 知道 | 路由器配置中常见 |
| 路由器常用配置项（OpenWRT） | 知道 | 知道各常用配置项的作用，家庭网络用得着 |
| 企业组网、复杂内网（STP 等交换机组网） | 不需要 | 主要考运维；corner case 繁琐，排障交给 AI |
