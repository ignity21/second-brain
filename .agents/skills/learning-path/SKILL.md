# 学习路径与陪学

两种用法：**建路径**（把某个主题的相关笔记排成学习顺序）和 **陪学**（沿路径或直接就某个问题讲解、出题）。笔记的写法遵循 `cc-note-writing`，结构和链接遵循 AGENTS.md。

## 建路径

路径正文、阶段标题、核心问题和待办说明统一用英语；保留节点 ID、学习进度和用于检索的中文别名，引用的 Anki 卡片标题保留原文以便查找。

在 `roamnotes-v2/LearningPath/` 建 `<topic>_learning_path.org`，标题如 `Statistics Learning Path`，`#+filetags: :learning:<大类>:`，并在根索引 `LearningPath/learning.org` 加一行 `* [[id:...][<主题>]]`。`LearningPath/` 是学习路径的专用大类，不是知识领域。

- **收集**：从相关大类的主索引树往下找，再用 `rg` 搜关键词，找出其他大类里的相关笔记，以及 `ankinotes/` 中对应的卡片。
- **深度**：不为排路径另问目标档位。`.agents/learning-goals.md` 里有该领域，就按它取舍；没有就收录全部相关笔记。
- **排序**：按前置依赖排，不照搬主树顺序。开头用一两句话写出整条路径的主线，即这个主题最终要回答的问题。
- **格式**：
  - 分阶段写，阶段是普通一级标题，带 `[/]` 统计；阶段超过 5 个时按 AGENTS.md 加 TOC。
  - 每步是一个 checkbox 列表项：链接最具体的笔记（不链接纯导航索引），写这一步要回答的核心问题；排序有理由时顺带说明。紧密相连的几篇可放在同一步，用 `→` 连接。
  - 相关 Anki 卡片按标题列在阶段末尾。
  - 缺的内容写成「待补」步骤，不预先建空笔记。
- **只读不改笔记**：读到的问题（事实错误、表述不准、符号冲突、放错位置的内容）写成对应步骤下的「待改：…」子项，学到该步时处理。
- **链接规则**：路径里的链接都是正文引用，不算主树父节点；被引用的笔记不反向链接路径。
- **验证**：按 AGENTS.md「按改动验证」检查路径文件和根索引。

## 陪学

用户说「继续 <主题> 路径」时，从第一个未勾选的步骤开始；直接提问时，先检索相关笔记。

- 在笔记已有的模型上接着讲，指出与旧笔记冲突的地方。讲解深度参考 `learning-goals.md` 中该领域的档位。
- 简单事实直接答。涉及机制时，从最小的具体例子出发，先让状态变化看得见，再引入术语。
- 用户说「不懂」，就换一种表示或缩小例子。随时间变化的过程（窗口滑动、状态演进、曲线）文字讲不清时，或用户说「画出来」时，可以用 `show-me` 做 HTML 逐步演示，放 scratchpad；标题和说明写清演示的是谁的什么、做了哪些假设，以及哪些部分超出当前话题。
- 用户说「考我」，就出一道稍有变化的题，等用户回答后再讲；答错的点按卡点处理。
- 用户说「这步跳过」时，勾选并进入下一步；该步「待改」里的事实错误照样直接修正，需要重写的留在原处。
- 用户确认这一步学完后（「这步学完了」「第 N 步学完了」）：
  1. 勾选该步，更新阶段的 `[/]` 统计（Emacs 外编辑时手动改数字）。
  2. 处理该步的「待改」：事实错误直接修正；需要按 `cc-note-writing` 重写的，结合用户在这一步的卡点改，不提前代写。
  3. 新出现的卡点按 `anki-cards` 做卡。
- 全部完成后，在路径开头写明完成日期。
