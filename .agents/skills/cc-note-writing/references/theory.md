# 理论 / 数学笔记

适用于数学、统计、机器学习原理等概念性知识，例如梯度下降、假设检验、特征值分解。

**默认档位**：「能判断」。与库类笔记相反，**这里的细节通常要保留**：能跟上并复现关键推导，本身就是理解；跳过推导只记结论，会失去判断结论适用条件的能力。AI 能给出推导，不构成删除推导的理由。

## 模板

```org
:PROPERTIES:
:ID:       <uuid4>
:END:
#+title: <Concept with domain context>

* Intuition          ; 一句话或一幅图说清它在做什么
* Definitions        ; 精确定义和符号约定
* Derivation         ; 关键推导，保留步骤和每步依据
* Worked Example     ; 小规模数值例子，可手算或用代码验证
* Assumptions        ; 成立条件；条件不满足时会怎样
* Misconceptions     ; 常见误解
* Connections        ; 前置概念、相关概念、应用（链接到代码类笔记）
* My Take :mine:
```

## 各章节要求

- **Intuition**：放在最前面，先给全局图像，再进入形式化内容。几何解释的配图放本大类的 `images/`。
- **Derivation**：推导是正式内容，不压缩成「易证」。每一步写明用到的定义或定理。公式使用 Org 的 LaTeX 语法（`$...$`、`$$...$$` 或 `\[...\]`）。
- **Worked Example**：数值要小到能手算核对。用代码验证时，代码放在本节，并写明结果。
- **Assumptions**：统计和机器学习方法的价值常常体现在适用条件上，例如独立性、正态性、凸性。应用于实际时，判断主要依赖这一节。
- **Connections**：链接到实现该理论的库笔记（例如统计概念 → statsmodels 笔记）。同一对笔记只保留一个方向，库笔记一侧不再回链，靠反链显示。

## 不记

- 能直接查到的公式表和数值表（分布表、导数表）。
- 与当前概念无关的历史和人物介绍。
