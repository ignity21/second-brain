# 误解 / 判断笔记

适用于从学习材料或讨论中提炼的「我原来错在哪」和「为什么这样选」。通常来自 `inbox-processing`，但也可手写。

**默认档位**：「能判断」。价值来自用户自己的卡点，材料本身随时能再查。

- **误解**：一般并入相关概念笔记的误解章节（按其模板为 `Misconceptions`、`Pitfalls` 或 `Corrected Model`），写成「原来以为 X → 实际 Y → 能区分二者的最小例子」；跨多篇的认知才单独成篇。生成 Anki 卡片的首选来源。
  - 只收用户确实有过的错误理解，不把用户的想法或领悟改写成误解。
  - 「答不上来」是知识缺口，不是误解：在正文对应章节写清楚并做卡片，不在误解章节复述正文。
- **判断**：写成决策记录：场景与约束、选择及理由、放弃的方案与原因、何时应重新评估。
- 误解和判断中「用户原来的理解」「选择理由」只能来自用户（处理收件箱时的问答或对话）；AI 不推测。
- 故障类使用 [experience.md](experience.md)。
